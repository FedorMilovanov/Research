# Инструменты сверки цитат серии SING

Два файла. Оба — часть репозитория, а не мусор в `/tmp`: песочница очищается между
проходами, и сверка, которую нельзя повторить, не считается сделанной (правило 63).

| Файл | Назначение |
|---|---|
| `fetch_corpora.sh` | скачать и распаковать все пять корпусов. Идемпотентно: повторный запуск ничего не качает. |
| `verify.py` | калибровка корпусов и сверка цитат в текстах серии |

Ничего, кроме стандартной библиотеки Python, не требуется.

## Быстрый старт

```bash
bash tools/fetch_corpora.sh                        # все корпуса в /tmp/bible (1 мин 10 с с нуля)
python3 tools/verify.py selftest                   # калибровка корпусов + проверка самого
                                                   # проверяльщика на восьми эталонах
python3 tools/verify.py all --report /tmp/otchet.md
```

`selftest` идёт в два этапа: сначала 19 контрольных мест по пяти корпусам (включая
кетив и кере одного стиха), потом восемь эталонов цитат, из которых четыре заведомо
неверные. Если инструмент подтверждает испорченную цитату, он считается сломанным.

Другой каталог корпусов: `BIBLE=/data/bible bash tools/fetch_corpora.sh` и
`python3 tools/verify.py all --corpus /data/bible`. Отдельный раздел:
`bash tools/fetch_corpora.sh wlc` (или `sblgnt`, `tr`, `lxx`, `rst`).

Проверить один файл: `--parts SING-005_INSTRUMENTS.md`.

## Что проверяется

Цитатные единицы извлекаются из восьми частей серии по трём видам:

- **врезка** — строка, начинающаяся с `>` (соседние строки склеиваются: перевод строки
  внутри цитаты в Markdown — пробел);
- **в строке** — фрагмент в обратных кавычках (греческий и еврейский);
- **русская** — фрагмент в кавычках «…».

Для каждой единицы берётся ближайшая ссылка выше (правило 59а) и цитата ищется как
последовательность слов в соответствующем месте корпуса: сначала по ссылке, потом в
названной книге, потом по всему корпусу (правило 61). Цитата, разорванная многоточием,
делится на сегменты: они должны идти в том же порядке, но не обязательно подряд.

## Статусы в отчёте

| Статус | Что значит | Что делать |
|---|---|---|
| **точно** | слова цитаты стоят в корпусе именно там, где сказано | ничего |
| **точно (в другой нумерации)** | то же, но номер главы или стиха другой (сдвиг псалмов МТ/LXX) | ничего: ожидаемо |
| **найдено в другом месте** | слова совпали слово в слово, но не там, куда указывала ближайшая ссылка | посмотреть: обычно ссылка из соседней строки (59а) |
| **расхождение** | похоже, но не совпадает (60–94 %) | разобрать: перевод серии, помеченный по правилу 49а, или дефект |
| **не найдено** | ниже 60 % | разобрать: список лексем, наша собственная речь или дефект |
| **список: найдено N из M** | перечень отдельных слов (через `·`), проверен каждый | ничего |

Русские цитаты дополнительно получают **пометку**: стоит ли в тексте указание, что это
перевод серии, а не Синодальный (правило 49а). Непомеченные расхождения печатаются
первыми — их и надо смотреть в первую очередь.

## Леммы и морфология еврейского текста

Помимо слов, индекс хранит номер леммы (Стронга) и морфологический код каждого слова:

```python
from verify import Corpus
c = Corpus()
c.verses_with_lemma(2485)              # все стихи с חָלִיל
c.forms_of_lemma(1984, 'Пс')           # [(книга, глава, стих, слово, морфкод)]
c.wlc_full()[('Пс', 150, 5)]           # [('הללוהו', '1984', 'HVpv2mp'), …]
```

**Считать еврейские слова надо по леммам, а не по подстрокам (правило 65).** Подстрока
`תהלה` не ловит форму `תהלות`, а подстрока `נבל` ловит омоним-глагол «увядать» — обе
ошибки дают числа, которых нет в тексте.

## Ловушки, уже найденные и закрытые

- Ссылка берётся из **своей** строки; ссылки из соседних табличных строк не наследуются
  (59а). Иначе таблица «перевод / Синодальный» даёт ложные расхождения.
- Кетив и кере стоят в разметке **рядом**, но не всегда один к одному: совпадение надо
  искать по соседству, иначе регулярное выражение съедает весь текст между двумя разными
  парами. Симптом — индекс без слова `הנבאימ` в 1 Пар 25:1.
- Заменяемое чтение надо оборачивать в `<w>…</w>`, иначе слово выпадает из разбора.
- Цитата без приставки ищется и с приставкой: клитики ו ב כ ל מ ה ש пишутся в кодексе
  слитно (правило 60б).
- Две цитаты подряд в одной врезке — две единицы (правило 62).
- Правка считается внесённой, только если она стоит там, где сделано утверждение, а не
  только в отчёте о правке (правило 66).
- Верификатор проверяют на ложных цитатах, а не только на верных (правило 64).
- Нулевое совпадение **не равносильно** статусу «нет корпуса»: признак «нет корпуса»
  возможен, только если корпус действительно не загружен.
- Патч инструмента — только с якорем, которого в файле ровно один (правило 58а), а
  шаблон писать в raw-строке, кириллицу и диапазоны копировать прямо из файла.

## Чего инструмент не делает

Он не проверяет богословие, верность перевода, орфографию за пределами цитат, дизайн и
музыку. Он отвечает на один вопрос: **стоит ли в первоисточнике то, что мы назвали
цитатой**. Всё остальное — ручная вычитка и решения владельца.

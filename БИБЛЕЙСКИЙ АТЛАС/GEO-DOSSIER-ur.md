# Ур Халдейский (`ur`) — образцовое гео-досье

**Реестр:** `gb-is-my-strength/data/atlas/places-draft.json` → id `ur` · **sameAs:** OpenBible `ur-1`, Wikidata `Q5373099` · **Карты:** avraam (`ur`) · **Статус досье:** образец формата, факты сверены с данными OpenBible (снапшот 2021-11) и общедоступной академической литературой; перед публикацией панели вариантов — добить источники Level A по каждому кандидату.

## 🚩 Суть вопроса

«Ур Халдейский» (אוּר כַּשְׂדִּים, Быт 11:28, 31; 15:7; Неем 9:7) — родина Авраама. Две конкурирующие традиции локализации, разнесённые на ~1000 км: южная Месопотамия (шумерский Ур) против северной Месопотамии (район Харрана/Урфы). Выбор влияет на ВСЮ геометрию первого этапа маршрута Авраама (Ур → Харран): южная теория даёт путь ~1000+ км вверх по Евфрату, северная делает Ур и Харран соседями.

## 🔍 Анализ и верификация

- **Level A:** раскопки Вулли надёжно дают шумерский Ур в Tell el-Muqayyar — но они доказывают идентификацию ГОРОДА Ур, а не тождество «Ур Халдейский = этот Ур» (это шаг интерпретации текста).
- **Level B:** консенсус современных академических атласов — южный Ур; при этом добросовестные справочники (Anchor Yale Bible Dictionary, статья «Ur») фиксируют северную гипотезу как живое меньшинство. Декадная модель OpenBible: 703 vs 53 — устойчивый перевес юга во всех декадах после 1969.
- **Эпитет «Халдейский»:** обе стороны используют его в свою пользу; честная подача — пояснить в панели, что эпитет датируется позже эпохи патриархов независимо от локализации.
- **Вывод по уровням:** южная локализация = `primary` (не `consensus`: меньшинство реально существует и опирается на текстуальную географию Быт 11:31), северная = именованный `candidate`-на-грани-`minor`; в UI показываем обе.

## 🗺 Решение для Атласа

1. Точка `ur` рисуется в Tell el-Muqayyar (30.962, 46.104) со статусом `primary` (бейдж «основная локализация»).
2. Панель «Варианты локализации»: Урфа как северная гипотеза с аргументами и указанием, что это меньшинство (текущие данные карты avraam уже содержат отдельную точку `urfa` — при миграции на реестр она становится не самостоятельным местом, а элементом identifications[] Ура; на карте остаётся как полупрозрачный кандидат-маркер со связью).
3. Маршрут Ур→Харран рисуется по южной теории (вдоль Евфрата через Мари), участок помечается `conjectured` (стиль пунктира по правилам уверенности маршрутов).
4. Текст панели не утверждает «точно известно» — формулировка: «основная научная локализация … существует северная гипотеза».

# БИБЛЕЙСКИЙ АТЛАС — исследовательские гео-досье

**Роль (ATLAS-CONTRACT Р5, gb-is-my-strength/docs/ATLAS-CONTRACT-2026-07-10.md):**
здесь живёт ДОКАЗАТЕЛЬНАЯ БАЗА географии Атласа — аргументация локализаций,
первоисточники, археология, хронологические таблицы. Код и данные карт живут
в gb-is-my-strength (`data/atlas/**`), аудиты — в AuditRepo. Этот раздел отвечает
на вопрос «ПОЧЕМУ мы ставим точку именно здесь и с каким уровнем уверенности».

## Правила (наследуют AGENT_RULES.md репозитория)

1. **Один кейс = один файл-досье.** `GEO-DOSSIER-<place-id>.md` — id из канонического
   реестра `gb-is-my-strength/data/atlas/places-draft.json` (потом `places/*.json`).
2. **Уровни источников:** Level A (раскопки/первичные публикации/стелы), Level B
   (академические атласы, словари, рецензируемые статьи), Level C (популярные и
   конфессиональные ресурсы), HOLD (не подтверждено первичкой).
3. **Словарь уверенности** — как в движке и контракте:
   `consensus | primary | candidate | alternative | caveat | minor | rejected`.
4. Досье заводится ТОЛЬКО для мест, где локализация спорная или интерпретация
   чувствительная (`identifications` > 1 или status ≠ consensus). Бесспорные
   места живут только в реестре данных.

## Стандарт структуры досье

```
# <Название> (<place-id>)
## 🚩 Суть вопроса          — что спорно и почему это важно для карты
## 📄 Кандидаты локализации — таблица: кандидат | статус | score | аргументы | источники
## 🔍 Анализ и верификация  — разбор аргументов по уровням A/B/C
## 🗺 Решение для Атласа    — что рисуем, каким статусом, что показываем в панели вариантов
## ⏳ Хронология вопроса    — история дискуссии (кратко)
```

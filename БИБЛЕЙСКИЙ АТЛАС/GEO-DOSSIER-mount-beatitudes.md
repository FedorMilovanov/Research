# Гора Блаженств (`mount-beatitudes`) — P2-досье

**Реестр:** `data/atlas/places/mount-beatitudes.json` · **Карты:** yeshua · **Статус в реестре:** needsReview (manualGeo, уровень B) — это досье закрывает review.
**Позиция сайта:** Нагорная проповедь (Мф 5–7) произнесена исторически; Евангелия НЕ называют гору по имени — вопрос не «какая из гор X», а «какую традицию показываем и как честно её подписываем».

## 🚩 Суть вопроса

Мф 5:1: «увидев народ, Он взошёл на гору»; Лк 6:17: «стал на ровном месте». Топонима нет ни у одного евангелиста. Значит: (а) любая точка на карте — ТРАДИЦИЯ, не текстовый факт; (б) надо честно решить текстовый вопрос Мф/Лк (гора vs ровное место); (в) статус точки не может быть выше `candidate/traditional` в принципе.

## 🔍 Анализ и верификация

1. **Текст (Мф «гора» vs Лк «ровное место»):** классические решения — (а) одна проповедь: уступ-терраса на склоне («ровное место» НА горе) — грамматически корректно для τόπου πεδινοῦ; (б) две разные проповеди (консервативная гармонизация части авторов). Подача сайта: основная справка — терраса на склоне (одна проповедь); позиция «две проповеди» — в справке как легитимная альтернатива. Текстологию не решаем «между делом» (§4).
2. **Level A:** руины византийской капеллы у Табхи (раскопки францисканцев, Bagatti) — древнейшая материальная фиксация традиции.
3. **Level B:** Эгерия (итинерарий, IV в.) — древнейшее письменное свидетельство; акустические исследования склона (полевые замеры Crisler, BA 1976) — вспомогательный аргумент правдоподобия, НЕ доказательство.
4. **Level C:** паломнические ресурсы (совр. храм 1938 г.) — фиксируют живую традицию.
5. Регистровая запись уже честна: manualGeo 32.882, 35.5556 (трад. хребет), notes «традиционная идентификация без библейского топонима».

## 🗺 Решение для Атласа

1. Точка остаётся на традиционном хребте над Табхой, статус **`candidate/traditional`**, подпись: «Гора Блаженств (традиционное место)».
2. Панель вариантов: Хаттин (`alternative`, крестоносская традиция) + честная оговорка «Евангелия гору не называют» (`caveat`).
3. Тултип: Мф 5:1/Лк 6:17 рядом — показать оба стиха, справка о «ровном месте на склоне».
4. **Реестр:** снять needsReview через `curatedConfirm` в review-decisions.json (обоснование: традиция подписана традицией, глубже без новых раскопок не решается) — выполняется вместе с этим досье.

## ⏳ Хронология вопроса

Эгерия (~381–384): «гора у Семи источников, где Господь учил блаженствам» → византийская капелла на склоне (IV–VI вв.) → крестоносцы переносят традицию на Рога Хаттина (Mons Beatitudinum) → францисканское возвращение к Табхе → 1938: храм Блаженств (Барлуцци) выше византийских руин → XX в.: акустический аргумент амфитеатра; сегодня практический консенсус паломнических конфессий — хребет над Табхой, при честном «текст горы не называет».

# ИМЛИ РАН — 40+ PDF archive pass

**Дата запуска:** 30 июля 2026 года  
**Статус:** `AUTOMATED ACQUISITION / OFFICIAL CC BY-ND CATALOGUE / PRIVATE DRIVE ARCHIVE / NO PDF COMMITS`

## Цель

Создать воспроизводимый исследовательский пакет минимум из 40 официальных PDF ИМЛИ РАН для:

- `TheLegendaryPoet`;
- `Research`;
- точечных историко-текстологических задач `gb-is-my-strength`;
- контрольных manifest/provenance записей в `AuditRepo`.

Крупные PDF не помещаются в git history. GitHub хранит только код, манифесты, SHA-256, права и редакционные выводы; бинарный архив предназначен для частного Google Drive `oldpoet2025@gmail.com`.

## Два официальных контура ИМЛИ

### 1. Историческая электронная библиотека `biblio.imli.ru`

На ней находятся академические корпуса Есенина, Блока, Хлебникова и другие издания до 2018 года. Первый workflow-проход был направлен туда, но GitHub-hosted runner не смог установить TCP-соединение с сервером: все попытки завершились `ConnectTimeout` до получения HTML или PDF.

Это **транспортный блокер среды**, а не отрицательная оценка источника. Ссылки на Есенина и другие старые корпуса сохраняются в master index и остаются приоритетными для отдельной загрузки из среды, имеющей доступ к серверу.

### 2. Текущий официальный издательский портал `ed-imli.ru`

Рабочий 40+ проход перенесён на официальный раздел **Russian Literature** издательства ИМЛИ РАН. Каталожные записи прямо содержат:

- название и библиографию;
- DOI/ISBN и год;
- прямую официальную PDF-ссылку;
- явную маркировку `Creative Commons Attribution-NoDerivatives 4.0 (CC BY-ND)`.

Скрипт принимает только PDF из карточек с такой явной лицензией. Зеркала, Telegram, Academia, ResearchGate, случайные облачные копии и страницы без установленного статуса исключены.

## Gate 40+

Скрипт проходит официальные страницы каталога:

```text
https://ed-imli.ru/index.php/en/russian-literature
https://ed-imli.ru/index.php/en/russian-literature?start=20
...
https://ed-imli.ru/index.php/en/russian-literature?start=120
```

Он:

1. собирает и дедуплицирует официальные PDF-ссылки;
2. принимает только блоки с явной `CC BY-ND 4.0`;
3. последовательно обрабатывает до 100 кандидатов;
4. продолжает после единичной сетевой или файловой ошибки;
5. останавливается после 40 действительных файлов;
6. проверяет сигнатуру `%PDF`;
7. вычисляет SHA-256, размер и число страниц;
8. фиксирует карточку, DOI, ISBN, год и права;
9. не подменяет неудачный файл сторонним зеркалом.

Workflow считается успешным только при одновременном выполнении условий:

- найдено не менее 40 eligible-кандидатов;
- реально скачано не менее 40 действительных PDF.

## Граница лицензии

`CC BY-ND 4.0` позволяет хранить и распространять неизменённый материал с надлежащей атрибуцией, но запрещает распространение адаптированной версии. Поэтому:

- PDF сохраняется байт-в-байт без изменения;
- нельзя публиковать «улучшенный», сокращённый или перемонтированный PDF как производную версию;
- извлечение и переработка иллюстраций для production-сайта не разрешаются автоматически этой архивной операцией;
- цитаты и факты используются с точной страницей и библиографией;
- для каждого публичного визуала проводится отдельная проверка прав.

## Правила обработки

1. PDF — исследовательский объект, а не автоматически готовый production-контент.
2. Parsed text не заменяет визуальную проверку страницы, когда важны подпись, иллюстрация или факсимиле.
3. Дубликаты выявляются по SHA-256.
4. `AuditRepo` хранит доказательства и решения, но не библиотечные бинарники.
5. Неудачная официальная ссылка остаётся `FAILED/HOLD`; зеркало не подставляется автоматически.
6. Старый корпус `biblio.imli.ru` не объявляется закрытым: его загрузка остаётся отдельной задачей из доступной сетевой среды.

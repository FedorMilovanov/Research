# Wikimedia Commons — 40+ открытых PDF по русской литературе

**Дата:** 30 июля 2026 года  
**Статус:** `OPEN-LICENSE DISCOVERY / BINARY ARCHIVE / PROVENANCE REQUIRED / PRODUCTION REVIEW SEPARATE`

## Задача

Сформировать реальный пакет не менее чем из 40 PDF, относящихся к русской поэзии, литературе, авторам Серебряного века и Айседоре Дункан, когда официальный сервер ИМЛИ не отдаёт достаточное количество бинарных файлов автоматизированной среде.

Этот корпус **не заменяет академический архив ИМЛИ**. Он решает другую задачу:

- собирает доступные открытые сканы и издания;
- сохраняет лицензионные метаданные;
- создаёт проверяемый частный исследовательский архив;
- помогает обнаруживать книги, старые журналы, переводы и изображения;
- даёт основу для дальнейшего ручного отбора.

## Разрешённые статусы

Скрипт принимает только оригинальные PDF Wikimedia Commons, у которых структурированное поле `extmetadata` сообщает один из статусов:

- Public Domain;
- CC0;
- CC BY;
- CC BY-SA.

Автоматически исключаются признаки:

- Fair use;
- all rights reserved;
- copyrighted;
- NonCommercial;
- NoDerivatives.

## Проверки каждого файла

Для каждого объекта сохраняются:

- название Commons-файла;
- страница описания;
- URL оригинального PDF;
- поисковый запрос, через который файл найден;
- краткое название лицензии;
- Usage Terms;
- требование атрибуции;
- автор/создатель;
- credit;
- исходный источник;
- дата;
- заявленный и фактический размер;
- число страниц;
- SHA-256;
- HTTP/content-type;
- точный статус загрузки.

Файл считается действительным только при наличии сигнатуры `%PDF`.

## Ограничение размера

По умолчанию один файл ограничен 120 МБ. Это защищает GitHub artifact и Google Drive от нескольких гигантских сканов, которые вытеснят весь остальной корпус. Пропущенный из-за размера объект остаётся в manifest со статусом `SKIPPED_TOO_LARGE`.

## Граница доверия

Лицензионная карточка Commons — существенное, но не абсолютное доказательство. Поэтому:

- PDF можно включить в частный исследовательский архив с сохранением всей карточки;
- перед публичной публикацией конкретной страницы или изображения нужно вручную проверить автора, дату, исходный скан, credit line и применимость лицензии;
- сомнительный provenance переводится в `HOLD`, даже когда автоматическая карточка выглядит открытой;
- для современных институциональных фотографий приоритет имеет политика учреждения-источника.

```text
commons-russian-literature-open-pdf-40plus
commons-russian-literature-40plus-manifest
```

## Хранение

После успешной проверки пакет предназначен для частного Drive:

```text
THE LEGENDARY POET — БИБЛИОТЕКА ИСТОЧНИКОВ — MASTER/
├── 01 — THE LEGENDARY POET/
│   └── Wikimedia Commons — открытые книги и сканы — 40+ PDF/
├── 03 — RESEARCH — ИССЛЕДОВАТЕЛЬСКИЙ АРХИВ/
│   └── COMMONS OPEN PDF 40+ — 2026-07-30/
└── 04 — AUDIT, ПРОВЕРКА И ЖУРНАЛ РЕШЕНИЙ/
    └── Commons manifests, licenses and SHA256/
```

GitHub хранит код и лёгкие manifest/rights-документы, но не должен превращаться в долговременное хранилище десятков крупных PDF.

## Запуск

```bash
python SOURCE_LIBRARY/tools/crawl_commons_open_pdfs.py \
  --target 40 \
  --per-query 20 \
  --max-candidates 250 \
  --max-file-mb 120 \
  --output-root open-access-pdf-archive
```

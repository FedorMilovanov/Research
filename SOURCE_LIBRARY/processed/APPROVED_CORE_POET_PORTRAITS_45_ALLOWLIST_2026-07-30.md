## Назначение

Allowlist закрывает исходную задачу: по пять исторических портретных референсов для девяти поэтов, чья внешность ранее получалась неузнаваемой:

- Иван Бунин;

- Константин Бальмонт;
- Фёдор Тютчев;
- Аполлон Майков;
- Валерий Брюсов;
- Александр Блок;
- Афанасий Фет.

## Методическая граница

Редакционная проверка подтверждает, что выбранный файл является портретом/фотографией/рисованным портретом, а не музеем, памятником, могилой, кораблём, книгой, автографом или иным объектом имени поэта.

Имя личности не выводится из внешности моделью. Связь с поэтом основана на точном Commons file title, person category и item metadata. Перед production-применением карточка источника остаётся обязательной.

## Лицензионный и технический gate

Downloader обязан заново получить для каждого из 45 Commons items:

- description page;
- original URL;
- MIME и размеры;
- `LicenseShortName`;
- `UsageTerms`;
- `AttributionRequired`;
- Artist;
- Credit;
- Source;
- Date.

Допускаются только Public Domain, CC0, CC BY и CC BY-SA. Затем:

- скачивается неизменённый оригинал;
- изображение декодируется;
- вычисляется SHA-256;
- байт-в-байт дубликаты отклоняются;
- создаётся папка по каждому поэту;
- сохраняются JSON/CSV manifest, attribution ledger и контрольные суммы;
- gate требует 45/45 успешных файлов и ровно 5 на каждого поэта.

## Production-использование

Reference archive предназначен прежде всего для проверки likeness и создания визуалов. Публичное размещение конкретного оригинала на сайте требует соблюдения его item-level credit line.

Для AI-портрета:

1. сравнивать результат минимум с двумя референсами;
2. использовать разные ракурсы и возрастные периоды;
3. не копировать ошибочную позднюю карикатуру как основной образ;
4. не считать один групповой кадр достаточным доказательством черт лица;
5. фиксировать, какие reference IDs использовались при финальной проверке.

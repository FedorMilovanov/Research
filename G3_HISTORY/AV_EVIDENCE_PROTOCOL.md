## Cost discipline
Do not spend paid GPT marketplace/app credits for media retrieval, transcription, screenshots or translation. Use public official sources and locally available deterministic tools first. No bulk upload of long transcripts to ChatGPT or repeated LLM passes. Local processing uses computing resources, not GPT app credits; no promise of zero overall compute/API cost. Never bypass paywalls, logins, anti-bot controls, DRM or platform download restrictions. For restricted items use official permitted playback or REQUEST_USER, not proxy evasion.

## Acquisition ladder
1. Identify exact session, date, speaker(s), event, official title, original URL/video ID, duration and language, and compare catalogue with actual recording. Deduplicate mirrors and reuploads; no inference that similarly titled sermon is the same recording.
2. Prefer author/publisher text and official human captions; use published transcript and native transcript panel (YouTube, SermonAudio, Desiring God, G3 official channel/catalogue, GNLI). A written manuscript is not timed speech. SermonIndex and other transcript mirrors are discovery leads; check provenance, date, exact version and reuse rights. Official archive index may be stale/inaccessible; record actual access, do not claim acquired from search snippet.
3. If permitted to download captions or media, preserve raw VTT/SRT/TTML/JSON3 with metadata in existing approved evidence storage; normalize to UTF-8 segments start_ms/end_ms/text with scripts and retain original hash. Use existing local tools (yt-dlp --list-subs, caption-only --skip-download --write-subs/--write-auto-subs where allowed, ffmpeg/ffprobe). Do not download full playlists by default. Native UI and official APIs/exports first. No unauthorized scraping.
4. If no caption and permitted local audio exists, use installed faster-whisper/whisper.cpp or existing offline ASR workflow; CPU-only for the current G3 lane under the owner’s NO CUDA directive; do not initialize CUDA or retry failed GPU jobs. GPU use in other lanes requires an applicable owner decision. Language English, timestamps, no translation-as-transcription. No paid cloud API without separate consent. Record model/version/settings, confidence and audio hash; speaker labels initially tentative. ASR is a search index, never a verified quotation.
5. Local search with ripgrep/SQLite FTS5/Python, normalize names and theological terms, select only useful context windows (e.g. 30–90 seconds), verify surrounding question and answer, speaker identity, negations, scriptural references, and exact audio of the proposed sentence. Do not claim listened if only text was read. If audio verification impossible retain quote HOLD; use permitted attributed written-source paraphrase if already accepted. No fabricated timestamps or generated historical screenshots.
6. Produce a narrow evidence packet and editorial handoff rather than full transcript in public Git. Full copyrighted media/captions stay in approved restricted storage only where permissible; no bulk copying or redistribution. Record original and RU translation separately, short proportionate excerpts only after rights review. Translation preserves doctrine and context; no invented quotations or claiming English ASR as Russian original.

## Session + excerpt manifest
One stable session ID (event/year/recording ID), source URL, date/time observed, speaker(s), title, duration, access state, recording/caption provenance, language, raw hash if acquired; excerpt ID, start/end milliseconds, exact original words (restricted as needed), translation, context/paraphrase, audio verification method/witness, matching screenshot timestamp and hash, claim/source mapping, rights status for quote/frame/embed independently, review status and original time-link (e.g. YouTube t=seconds for actual verified recording). Each screenshot is from the same recording at the stated time; capture visible speaker/context, remove only player chrome if permitted and without misleading crop; not necessarily the exact frame of every quoted word. No audio/frame verification inferred from caption timestamps alone. Distinguish announced session, catalogued media, played audio, transcript read, verified excerpt, and public-ready approval.
Use existing media rights ledger / evidence vocabulary, not a competing authority registry. A catalogued item or timestamp does not imply publication rights. For a disputed original (notably 2021 MacArthur live/prerecorded) keep current HOLD until independent exact original controls; no upgrading old inaccessible audio. For Buck item-level claims require exact sermon, original commentary edition, complete context and separate review; do not use clipping or images to insinuate guilt.

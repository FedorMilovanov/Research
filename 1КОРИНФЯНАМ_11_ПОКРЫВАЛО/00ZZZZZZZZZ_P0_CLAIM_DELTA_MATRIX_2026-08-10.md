# 4. Anti-overclaim gates for the next agent

Before changing a project grade from a P0 excerpt, ask:

1. Is this definitely the **current edition**?
2. Is the excerpt inside the correct 11:2–16 argument rather than intro/index/review?
3. Is the note/footnote context present?
4. Does the author state the view or merely report another scholar?
5. Is the wording a conclusion or one option under review?
6. Is an edition/page mismatch possible?
7. Has newer current scholarship materially altered the historical premise?

If any answer is unknown:

```text
GRADE_CHANGE = BLOCKED
STATUS = HOLD
```

# Стандарт уровней доказательства и калибровки тезисов — серия 1 Кор. 11

**Статус:** `FOUNDATION / MANDATORY`
**Образец:** `ТРУДНЫЕ ТЕКСТЫ/00_GENESIS6_EVIDENCE_LEVELS_AND_CLAIM_CALIBRATION_STANDARD_XXXVII.md` (адаптация)
**Подчинён:** `00_MASTER_INDEX_AND_SERIES_STRUCTURE.md`

---

## 1. Назначение

Каждый тезис серии должен показывать:

1. какой тип данных его поддерживает;
2. что непосредственно засвидетельствовано;
3. что реконструировано;
4. что выведено;
5. какие альтернативы остаются открытыми;
6. является ли вывод текстологическим, историческим или богословским.

---

## 2. Семь уровней доказательства (адаптация)

### Уровень A — прямое утверждение канонического текста

Примеры:

- 11:5 — женщина молится и пророчествует в собрании (текст предполагает это как реальность);
- 11:3 — κεφαλή-отношения названы: Бог — Христос, Христос — муж, муж — жена;
- 11:10 — женщина должна иметь ἐξουσίαν ἐπὶ τῆς κεφαλῆς διὰ τοὺς ἀγγέλους;
- 11:16 — «мы такого обычая не имеем».

Публикационный язык: «текст прямо говорит», «в предложении субъектом является…».

Нельзя автоматически превращать прямое утверждение в описание неназванного механизма:

```text
ЖЕНЩИНА МОЛИТСЯ И ПРОРОЧЕСТВУЕТ (11:5)           → ПРЯМО СКАЗАНО
ПОКРЫВАЛО = ТКАНЬ (ВУАЛЬ)                          → НЕ СКАЗАНО ПРЯМО
ПОКРЫВАЛО = ДЛИНА ВОЛОС                            → НЕ СКАЗАНО ПРЯМО
АНГЕЛЫ = СВЯТЫЕ АНГЕЛЫ / ПАДШИЕ / ПОСЛАННИКИ      → НЕ СКАЗАНО ПРЯМО
```

### Уровень B — непосредственно сохранившиеся артефакты и рукописи

- чтения NA28/UBS6 и аппарат (то, что реально читается в свидетелях);
- археология: портреты, статуи, монеты, фрески Коринфа и Рима (Остер, Гилл, Томпсон);
- письменные свидетельства I в. (Плутарх, Апулей, Дион Хрисостом, римское право).

Обязательные формулы: «на портрете сохранилось», «Плутарх пишет», «в аппарате NA28 указано…». Запрещено называть «текстом рукописи» реконструкции и переводческие глоссы.

### Уровень C — редакторское/историческое восстановление и гипотезы

- реконструкция «что происходило в Коринфе» (Winter: «новые женщины»; Остер: capite velato; Fee/Payne: причёски);
- переводческие решения («знак власти» в Синодальном — это толкование, а не буква);
- теория «ἐξουσία = mistranslation арамейского „вуаль“» (NAB footnote) — гипотеза.

### Уровень D — литературная и богословская связь

- связь 11:10 «ангелы» с Быт. 6:1–4 (Тертуллиан и др.);
- связь 11:3 с тринитарными дебатами;
- связь 11:8–9 с Быт. 2.

### Уровень E — канонико-богословский вывод

- «порядок творения остаётся нормативным»;
- «текст культурно обусловлен»;
- «принцип чести и порядка универсален, форма применима в культуре».

Каждый вывод уровня E обязан явно перечислить опоры уровней A–D.

## 3. Шкала уверенности

```text
CERTAIN   — прямое утверждение текста или бесспорный артефакт
HIGH      — сильный консенсус при открытых деталях
PROBABLE  — лучшая гипотеза при конкурирующих альтернативах
POSSIBLE  — правдоподобная гипотеза без решающих данных
OPEN      — данных недостаточно; несколько жизнеспособных вариантов
```

Примеры калибровки:

| Тезис | Уровень |
|---|---|
| Павел хвалит коринфян за держание преданий (11:2) | A / CERTAIN |
| Женщины в Коринфе молились и пророчествовали в собрании (11:5) | A / CERTAIN (текст предполагает) |
| «Покрывало» = ткань | C / PROBABLE (традиция)…OPEN (спор) |
| «Покрывало» = волосы/укладка | C / POSSIBLE…PROBABLE (Fee, Payne, отчасти Шрейнер) |
| κεφαλή = «власть над» | C+D / PROBABLE (Грудем, Фитцмайер, лексиконы) |
| κεφαλή = «источник» | C / POSSIBLE (Фи и др.), оспаривается |
| Ангелы 11:10 = святые ангелы-хранители | C+D / PROBABLE (Златоуст, Кальвин, Гилл, Тислтон) |
| Ангелы 11:10 = падшие ангелы (Быт. 6) | D / POSSIBLE (Тертуллиан; ранняя традиция) |
| Ангелы 11:10 = посланники/священники | C / POSSIBLE (Winter, Амвросиаст, Ефрем) |
| 11:2–16 — аутентичный Павел | A+B / HIGH (рукописная традиция P46 и далее; против — литературные теории) |
| 11:2–16 — поздняя интерполяция | C / POSSIBLE (Walker, Cope), большинство отвергает |

## 4. Правила формулировок

1. Прямой текст — без оговорок.
2. Историческая реконструкция — всегда с именем гипотезы и её сторонников («по реконструкции Winter…», «гипотеза Fee…»).
3. Толкование в переводе не выдаётся за оригинал (Синодальный «знак власти над нею» — толкование ἐξουσία).
4. Цитаты — только по протоколу EXACT_QUOTE с локатором (см. `00_SOURCE_WEIGHT_AND_ACQUISITION_PLAN.md`).
5. Консервативный ряд — основной; либеральные позиции — только атрибутированные примеры с указанием, что это позиция автора, а не консенсус.
6. Каждое «не знаем» фиксируется честно (по образцу Ходжа: «I do not know what it means» — тоже документируется как честная позиция).

## 5. Открытые методологические риски

- проекция современных гендерных дебатов на I век;
- чтение 11:2–16 через призму 14:34–35 (и наоборот);
- смешение «что Павел описывал» и «что Павел предписывал»;
- доказательство тезиса числом цитат (запрещено, см. стандарт веса источников);
- использование популярных сайтов вместо полных книг (запрещено для quote-safe утверждений).

## 1. Шкала

- **A / DIRECT-HIGH:** прямо следует из греческой конструкции, проверяемого текста/рукописного факта или независимого исторического первоисточника.
- **B / PROBABLE:** лучшее объяснение текущей совокупности данных, но существует серьёзная альтернатива или реконструктивный шаг.
- **C / POSSIBLE:** жизнеспособная конкурирующая модель, которой не хватает объяснительной силы/прямой опоры для ведущего статуса.
- **D / SPECULATIVE-HISTORY:** полезна как история интерпретации/дебата, не как основание публикационного вывода.
- **HOLD:** требует прямого locator/page/object acquisition; не повышать степень уверенности по памяти или proxy.

## 3. Явные supersession-corrections к agent corpus

Следующие прежние формулы считаются **SUPERSEDED** и не должны возвращаться в будущие статьи/досье без нового прямого доказательства:

1. **`NA29 current/published`** → неверно на 2026-08-09; официальный publisher ставит релиз на **2027-02-28**.
2. **`Pauline ECM complete`** → неверно; опубликованные новые ECM-text changes, на которые ссылается GNT6, относятся не к завершённой ECM Corinthians.
3. **`75 strictly verified sources`** → переименовать смысл в **mixed verification registry**: часть записей page/direct, часть bibliographic/proxy/locator-hold. Число источников нельзя использовать как substitute for verification depth.

5. **`κεφαλή = source refuted / GRADE X`** → superseded; scholarly dispute доказуемо существует.
6. **`hair-only refuted / GRADE X`** → superseded; модель слабее в текущем синтезе, но реальна.
7. **`holy angels = certain`** → B/PROBABLE; текст не идентифицирует их.
8. **`Watchers = Paul’s direct meaning`** → C; древняя Tertullian interpretation, не explicit Pauline identification.
9. **`Roman capite velato = demonstrated Corinthian Christian practice`** → B reconstruction, хотя сам Roman ritual background = A.
10. **`all women/unmarried scope settled`** → OPEN; wives-vs-all-women остаётся спорным.

## 4. Publication language

Разрешённые формулы:

- «текст прямо говорит…» только для A-level textual/syntactic facts;
- «вероятнее всего», «ведущее чтение», «лучше объясняет» для B;
- «возможная древняя/современная модель» для C;
- «предлагалось» для D;
- «не установлено», «требует прямой страницы/объекта» для HOLD.

Запрещённые без A-level доказательства: **«доказано», «однозначно», «окончательно опровергнуто», «все учёные», «археология установила именно ситуацию Павла»**.

# 10. Антиповторные правила

## Правило 1. Один полный разбор

Каждая греческая или еврейская конструкция получает полный разбор только в статье-владельце.

В других статьях:

```text
1 предложение
+ ссылка
+ только новый функциональный вывод
```

## Правило 2. Не пересказывать всю позицию заново

Например, Статья 3 не должна снова давать пять страниц Sethite view. Достаточно:

> «Человеческие модели Быт. 6 рассмотрены в Статье 1; здесь проверяется, требует ли Иуда самостоятельного ангельского события».

## Правило 3. Енох не появляется раньше канонического текста

Во всех статьях порядок:

```text
канонический текст
→ версии
→ канонический интертекст
→ 1 Енох как контекст
```

## Правило 4. Один текущий verdict

Финальный итог по referent принадлежит:

`GENESIS6_FINAL_POSITION_AND_CLAIM_BOUNDARIES.md`

Статья 1 выражает его публично. Остальные статьи не создают конкурирующий verdict.

## Правило 5. Не повторять disclaimers целиком

Создать общий reusable callout:

```text
Эта серия не утверждает:
— генетическую порчу человечества;
— чистую кровь Ноя;
— вторую инвазию;
— каноничность всего Еноха;
— полную тождественность Нефилимов и детей.
```

В каждой статье использовать только релевантные пункты.

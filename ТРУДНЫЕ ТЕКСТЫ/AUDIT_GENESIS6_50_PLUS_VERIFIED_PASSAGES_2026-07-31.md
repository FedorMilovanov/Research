# 1. Задача

Провести аудит серии БЫТИЕ 6 и зафиксировать 50+ верифицированных проходов (claim-level verification points), которые точно подтверждают данные серии. Это аудит, а не публикация.

---

# 2. Методология подсчёта

Подсчёт ведётся по трём пересекающимся слоям:

1. **LI 44-точечный манифест** — курированные контрольные точки, каждая проверена по конкретному тезису.
2. **Постраничные claim-to-citation ledgers** (XLVI–XLVII) — дополнительные верифицированные claims с точным статусом проверки.
3. **XLIX control run** — 62+ узла: ECM2/NA28 primary line, Codex Sinaiticus, 4Q204, P72.

Дублирование между слоями исключено: каждый проход считается один раз.

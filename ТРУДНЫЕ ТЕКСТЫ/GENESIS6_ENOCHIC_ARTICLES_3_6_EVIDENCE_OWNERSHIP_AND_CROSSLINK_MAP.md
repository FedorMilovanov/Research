# 8. Правила cross-link

В соседней статье разрешены:

1. одно предложение с установленным результатом;
2. один короткий абзац, если без него теряется логика;
3. ссылка на статью-владельца;
4. мини-таблица только при новой функции.

Запрещены:

- повторный полный исторический экскурс;
- повторная таблица рукописей;
- повторная защита или опровержение каноничности;
- пересказ Книги Стражей в статье об Иуде;
- заполнение лакуны одной рукописи по другой версии без маркировки;
- перенос поздней версии в ранний фрагмент как видимого текста.

# 9. Технический контроль каждого рукописного утверждения

```text
CLAIM
→ exact work
→ exact witness
→ siglum
→ plate / folio / page
→ visible letters
→ restored letters
→ editor
→ alternative restoration
→ confidence
→ publication permission
```

Фраза «Кумран доказывает» запрещена без указания конкретного объекта и сохранности.

# 10. Итоговый принцип

> Сначала читатель узнаёт, что такое составной корпус 1 Еноха; затем отдельно читает Книгу Стражей и Книгу Исполинов; только после этого рассматривает богодухновенное использование Иудой преданий о Моисее и Енохе. Такая последовательность сохраняет приоритет Писания, уважает материальные рукописи и не превращает енохическую литературу в одну неопределённую «книгу».

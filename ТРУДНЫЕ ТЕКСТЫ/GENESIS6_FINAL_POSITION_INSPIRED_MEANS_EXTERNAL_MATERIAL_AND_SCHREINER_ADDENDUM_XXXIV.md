# 4. Warfield’s controlling mechanism

Уорфилдская модель concursus становится основным механизмом проекта:

```text
провиденциальная подготовка событий
→ сохранение сведений
→ подготовка личности автора
→ исследование / память / документы / рассуждение
→ преобладающее руководство Духа
→ God-breathed Scripture
```

Это исключает две ошибки:

```text
МЕХАНИЧЕСКИЙ ДИКТАНТ КАК ЕДИНСТВЕННЫЙ СПОСОБ
→ отвергается

АВТОНОМНЫЙ ЧЕЛОВЕЧЕСКИЙ ТЕКСТ С ПОЗДНИМ БОЖЬИМ ОДОБРЕНИЕМ
→ отвергается
```

# 6. Формула для Моисея

> Бог является источником истинного знания Быт. 1–11 и суверенно открыл его через Моисея. Моисей мог пользоваться любыми угодными Богу достоверными средствами — памятью, ранними записями, родословиями, традиционными именами и обычным исследованием, — но точный естественный механизм не раскрыт. Поэтому проект не отрицает человеческие средства и не выдумывает их. Ни один языческий миф не установлен как источник текста или истины Быт. 6.

---

# 7. Формула для внешней истины

> Падший человек способен по общей благодати сохранять или произносить отдельные истины. Святой Дух может богодухновенно избрать истинное предложение из внешнего автора. При этом истинность одного предложения не утверждает всё произведение, а канонический авторитет исходит от Бога, вдохновившего Писание.

Пример:

```text
КРИТСКИЙ ПОЭТ
→ сказал конкретную истину

ПАВЕЛ
→ «свидетельство это истинно»

ВСЯ КРИТСКАЯ РЕЛИГИЯ
→ не утверждена
```

---

# 8. Формула для Иуды и 1 Еноха

> Иуда весьма вероятно непосредственно использует 1 Енох 1:9. Он канонически утверждает истинность пророческого содержания, применяет пришествие Господа ко Христу и обличает лжеучителей. Это не делает весь составной корпус 1 Еноха богодухновенным. Остаётся открытым, восходит ли точная формула к реальному допотопному пророчеству, представляет ли истинную позднюю литературную атрибуцию или сохраняет древнее ядро в развитой форме.

# 9. Коррекция популярной формулы Шрайнера

Schreiner’s открытый комментарий говорит, что никакая основная группа христиан не считала 1 Енох каноническим.

Для публикации нужна историческая точность:

```text
ЭФИОПСКАЯ ПРАВОСЛАВНАЯ ТРАДИЦИЯ
→ включает 1 Енох в более широкий канон

БОЛЬШИНСТВО ИУДЕЙСКИХ И ХРИСТИАНСКИХ КАНОНИЧЕСКИХ ТРАДИЦИЙ
→ не включает
```

Правильная формула:

> Цитирование Иудой не доказывает каноничность всего 1 Еноха для всеобщей Церкви. Исторически необходимо отдельно признать его канонический статус в Эфиопской православной традиции.

# 11. Формула для сравнительных параллелей

Внешняя параллель может служить:

1. историческим фоном;
2. богословским контрастом;
3. свидетельством общей благодати;
4. возможной искажённой памятью;
5. историей рецепции;
6. объектом критического возражения;
7. контекстом позднего неканонического текста.

Она не может без независимого доказательства служить:

- источником Бытия;
- ключом, отменяющим еврейский текст;
- доказательством неисторичности;
- основанием для JEDP;
- способом импортировать поздние детали.

# 13. Уровни скепсиса

## Не безумный скепсис

Мы не отвергаем утверждение потому, что автор:

- не TMS;
- либеральный;
- использует статистику;
- сравнивает мифы;
- предлагает литературную связь.

Мы проверяем доказательство.

## Библейский скепсис

Мы особенно осторожны, когда вывод:

- противоречит ясному самосвидетельству Писания;
- зависит от отсутствующего документа;
- предполагает направление по одному сходству;
- смешивает рукопись и композицию;
- превращает мировоззренческую параллель в идентичность;
- скрывает критические labels внутри алгоритма;
- использует источник для деисторизации текста.

# Марафон XXIV: полный повторный ingest PDF, исправление статусов и внешняя верификация

**Дата:** 23 июля 2026 года  
**Статус:** `DEEP-PASS-XXIV-A / DIRECT-TO-MAIN / FULL-PDF-REINGEST / DUPLICATE-CONTROL / 50-PLUS-WEB-WAVE / NO-FALSE-FULL-READ / CANONICAL-UPDATE-REQUIRED`

---

## 1. Причина нового прохода

После марафона XXIII корпус был структурирован, но пользователь повторно предоставил большую группу PDF, часть которых уже использовалась ранее. Новый проход не предполагает механического повторения прежних карточек. Его задача:

1. установить, какие файлы действительно полные;
2. выявить точные дубли и фрагментарные извлечения;
3. проверить, не был ли обзор или рецензия ошибочно принят за монографию;
4. перечитать ключевые главы по существу, а не только введения и аннотации;
5. извлечь аргументы, которые меняют причинную, текстологическую или публикационную модель;
6. сопоставить их с канонической позицией проекта;
7. провести широкую интернет-верификацию оставшихся P0-вопросов;
8. обновить только те выводы, которые выдерживают контроль первичного текста.

---

## 2. Неизменяемый порядок работы

```text
FILE IDENTITY
→ HASH / PAGE COUNT / TITLE PAGE
→ FULL / EXCERPT / REVIEW / TRANSLATION / DUPLICATE
→ RELEVANT CHAPTER
→ LINEAR READING OF RELEVANT RANGE
→ PRIMARY CLAIM
→ TEXTUAL DEPENDENCE
→ RESTORATION DEPENDENCE
→ ALTERNATIVE READING
→ EFFECT ON CANONICAL POSITION
→ ARTICLE OWNER
```

Нельзя:

- считать файл полным по имени;
- считать одинаковые названия разными источниками;
- переносить вывод из эфиопского текста в арамейский без контроля;
- печатать реконструкцию как видимые буквы;
- считать критическое издание безошибочным прочтением;
- использовать древнюю рецепцию как автоматическое доказательство значения Бытия;
- использовать сильный довод за небесный референт как доказательство ангельской физиологии.

## 3. Новая маркировка файлов

```text
F-MONO      полная монография
F-COMM      полный комментарий
F-ED        полное критическое издание
F-ARTICLE   полная статья
F-TRANS     полный перевод без полного комментария
F-COLLECT   полный сборник статей
PART        извлечение / front matter / отдельная глава
REVIEW      рецензия на книгу
BIBLIO      библиографический обзор
DUP-EXACT   точный бинарный дубль
DUP-CONTENT то же произведение в ином файле или формате
PERIPHERAL  полезно для соседней статьи, но не для Быт. 6:1–4
HOLD        личность файла или объём не установлены
```

---

## 4. Новая маркировка утверждений из фрагментов

Для каждого арамейского чтения фиксируются четыре независимых параметра:

```text
INK       видимые буквы
PARSE     грамматический разбор видимого
RESTORE   восстановление утраченного
MODEL     более широкая литературная модель
```

Шкала зависимости:

```text
R0 — вывод следует из полностью видимого текста
R1 — минимальное и почти неизбежное восстановление
R2 — вероятное восстановление, но есть реальная альтернатива
R3 — значительная реконструкция предложения или контекста
R4 — вывод зависит от жанра, поздней версии или общей модели
```

Утверждение уровня `R3–R4` нельзя использовать как главный аргумент в статье без показа альтернативы.

## 5. Критический принцип Stadel

Повторно прочитанная статья Christian Stadel 2024 показывает:

- даже видимые последовательности букв в крайне фрагментарном арамейском тексте могут допускать разные синтаксические деления;
- грамматика, предполагаемый жанр и восстановленный контекст влияют друг на друга по кругу;
- официальное издание вынуждено выбрать одну интерпретацию, но сам факт публикации не делает её единственной;
- редактор, предпочитающий позднюю жанровую параллель, может получить совершенно иной текст, чем редактор, предпочитающий грамматику засвидетельствованных букв;
- читатель обязан исследовать альтернативы, иначе он комментирует современный перевод, а не арамейский оригинал.

Это становится обязательным правилом для 4Q201, 4Q202, 4Q204, 4Q206/206a и Книги Исполинов.

## 6. Цели марафона

Марафон считается завершённым, когда созданы:

1. полный аудит идентичности всех присланных PDF;
2. отдельный глубокий ingest Nickelsburg по зависимости Бытия и 1 Еноха;
3. отдельный глубокий ingest VanderKam 2024 о людях и причине Потопа;
4. правила фрагментарной реконструкции по Stadel и Machiela;
5. реестр текстуальной множественности енохической традиции;
6. пересмотр влияния этих данных на финальную позицию;
7. пакет доказательств для Статьи 1;
8. исправленный список приобретения;
9. closeout с точными коммитами и честными пробелами.

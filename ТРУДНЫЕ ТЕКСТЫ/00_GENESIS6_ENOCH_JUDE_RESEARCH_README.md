# 6. Внешний материал и заимствования

## 6.1. Три значения «источника»

```text
ИСТОЧНИК ИСТИНЫ
→ Бог

ИНФОРМАЦИОННОЕ СРЕДСТВО
→ свидетель / архив / память / документ / исследование

ЛИТЕРАТУРНЫЙ ANTECEDENT
→ конкретная более ранняя словесная форма
→ устанавливается доказательствами
```

## 6.2. Доказанная связь признаётся

```text
ИУД. 14–15 ↔ 1 ЕНОХ 1:9
→ длинная специфическая словесная связь
→ литературное использование весьма вероятно
```

## 6.3. Тематическая параллель не превращается в заимствование

```text
БЫТ. 6 ↔ ГЕСИОД / APKALLU / ЯЗЫЧЕСКИЕ ГЕРОИ
→ сравнительные мотивы
→ конкретный литературный antecedent Моисея не установлен
→ миф не является источником Бытия
```

Допустимы как подчинённые вопросы:

- искажённая память о реальном событии;
- независимая идолопоклонническая конструкция;
- память о реальных героях и народах;
- поздняя диффузия;
- богословский контраст;
- история рецепции.

Конкретная модель не объявляется доказанной без данных.

## Нефилимы

```text

→ Нефилимы были

וילדו להם
→ происходили рождения
→ объект «Нефилимов» не выражен

→ вероятнее всего рождённые названы могучими
→ древние версии часто полностью отождествляют категории
```

Публикационный verdict:

> Нефилимы, рождённые и могучие тесно связаны и, вероятно, в значительной степени тождественны. Текст не раскрывает физиологический механизм и послепотопную преемственность.

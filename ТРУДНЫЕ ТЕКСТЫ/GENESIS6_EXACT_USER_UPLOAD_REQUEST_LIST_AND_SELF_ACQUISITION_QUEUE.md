# Точная очередь загрузок и самостоятельного приобретения

**Дата:** 23 июля 2026 года  
**Статус:** `CANONICAL-SOURCE-QUEUE / NINE-ARTICLE-OWNERSHIP / SELF-ACQUIRE-FIRST / CLOSED-SOURCES-ONLY / NO-DUMPING`

## 1. Главное правило

Пользователю не нужно загружать общий массив книг.

Запрос допустим только если:

1. полный текст действительно закрыт;
2. нужен конкретный критический аппарат;
3. требуется publishable facsimile;
4. доступен только abstract/preview;
5. источник является незаменимым владельцем позиции;
6. точные страницы способны изменить тезис или аппарат.

```text
official open route
→ institutional repository
→ public-domain edition
→ existing user library
→ author upload
→ controlled borrow
→ только затем user request / ILL
```

Главный открытый ledger:

`OPEN_SOURCE_SELF_ACQUISITION_70_PLUS_VERIFIED_ROUTES_LEDGER.md`

# 12. Формат полезной загрузки

Не присылать случайную книгу целиком, когда нужны 5 страниц.

Предпочтительно:

```text
название
+ title page
+ copyright/bibliographic page
+ relevant section
+ preceding/following page
+ footnotes
+ bibliography
+ apparatus sigla page
```

Для рукописи:

```text
full folio
+ high-resolution crop
+ shelfmark
+ folio/fragment/line
+ catalogue metadata
+ permission terms
```

## 13. Итог

> Пользовательская загрузка стала последним, а не первым этапом приобретения. Текущая очередь содержит только реально закрытые критические владельцы, apparatus pages и publishable images. Всё, что доступно официально, институционально, в public domain или уже загружено, агент обязан добывать и проверять самостоятельно.

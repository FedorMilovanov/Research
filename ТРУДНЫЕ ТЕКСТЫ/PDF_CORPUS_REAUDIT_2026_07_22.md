# Повторный аудит PDF-корпуса — 22 июля 2026 года

**Версия:** 1.0  
**Статус:** `AUTHORITATIVE-INGEST-LEDGER / ACTIVE-RESEARCH / NO-PDF-BINARIES-IN-REPO`  
**Назначение:** зафиксировать без двусмысленности, какие PDF реально получены, какие являются дублями, что уже исследовано глубоко, что прочитано только целевыми проходами, а что ещё требует систематической обработки.

---

## 1. Почему потребовался повторный аудит

В длинной исследовательской сессии возникло несколько типов путаницы:

1. файловое имя не всегда совпадало с фактическим изданием;
2. одинаковые PDF загружались под разными именами;
3. компактный перевод 1 Еноха смешивался в обсуждении с полноразмерным комментарием Hermeneia;
4. текстовый индекс PDF не видел image-only фототаблицы Milik 1976;
5. целевой глубокий разбор отдельных глав иногда описывался слишком широко, будто вся многосотстраничная книга прочитана построчно;
6. ранее загруженный полный том мог отсутствовать в последнем пакете, но сохраняться среди файлов прежних сообщений.

Поэтому настоящий реестр строится не по имени файла, а по четырём уровням:

```text
физический файл и SHA-256
→ точная библиографическая идентификация
→ отношение к другим файлам: самостоятельный / дубль / извлечение
→ фактическая глубина проведённого исследования
```

## 2. Словарь статусов глубины

| Статус | Значение |
|---|---|
| `DEEP-FULL-ARTICLE` | короткая статья прочитана целиком, включая аргументацию, примечания и выводы |
| `DEEP-FULL-REVIEW` | рецензия прочитана целиком и сопоставлена с рецензируемой книгой |
| `DEEP-TARGETED-BOOK` | многосотстраничная книга проверена по титульным данным, структуре, методологии и всем ключевым для проекта местам, но не прочитана линейно от первой до последней страницы |
| `PARTIAL-SELECTED-CHAPTERS` | изучены релевантные главы или статьи сборника; остальная книга ещё не индексирована подробно |
| `INITIAL-DEEP-PASS` | выполнен первый системный проход, выявлены главные выводы и проблемные места; необходим второй проход |
| `IDENTIFIED-NOT-DEEP` | источник точно установлен, но содержательный разбор ещё не выполнен |
| `EXACT-DUPLICATE` | файл полностью совпадает с другим по SHA-256 |
| `SUPERSEDED-PARTIAL` | файл представляет только начальные страницы или извлечение из уже имеющегося полного издания |
| `PRIOR-UPLOAD-RETAINED` | источник не входит в последний пакет, но ранее был реально загружен и остаётся доступным |

### Запрещённая формула

> «Книга полностью изучена», если фактически проверены только выбранные главы.

### Допустимая формула

> «Выполнен глубокий целевой проход по методологии и ключевым для текущего кейса местам; линейное постраничное чтение всего тома ещё не завершено».

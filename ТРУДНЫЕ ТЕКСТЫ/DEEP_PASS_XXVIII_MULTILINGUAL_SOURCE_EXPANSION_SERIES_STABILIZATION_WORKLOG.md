# Марафон XXVIII: многоязычное расширение источников и стабилизация серии

**Дата:** 23 июля 2026 года  
**Статус:** `OPEN / DIRECT-TO-MAIN / 50-PLUS-SOURCE-SEARCH / MULTILINGUAL / JEWISH / GERMAN / PATRISTIC / SERIES-STABILIZATION`

## 1. Цель

Стабилизировать весь исследовательский корпус и будущую серию статей после завершения текстологического Marathon XXVII.

Задачи:

1. найти недостающие полные книги, статьи, диссертации, критические издания и первоисточники;
2. пройти не только англоязычную, но также немецкую, еврейскую, французскую, нидерландскую, итальянскую и другие релевантные традиции;
3. собрать древнеиудейские, раввинистические, средневековые еврейские и патристические толкования;
4. отделить реальный полный доступ от библиографического следа, рецензии, preview и вторичного пересказа;
5. расширить карту человеческих позиций без карикатуры;
6. проверить, какие важные консервативные, евангельские и конфессиональные комментарии ещё отсутствуют;
7. назначить каждому источнику владельца вопроса и место в серии;
8. не допустить дублирования между шестью статьями;
9. составить точный список материалов, которые пользователю действительно полезно дополнительно загрузить;
10. определить stop-criteria, после которых исследование должно переходить в финальную редактуру.

Все изменения вносятся непосредственно в `main`. Ветки и PR не создаются.

## 2. Исходные ограничения

### 2.1. Scripture-first

```text
ПИСАНИЕ
→ первичный письменный авторитет

ДРЕВНИЕ ВЕРСИИ
→ текстовая передача и ранняя экзегеза

ИУДЕЙСКАЯ И ХРИСТИАНСКАЯ РЕЦЕПЦИЯ
→ история понимания

СОВРЕМЕННАЯ НАУКА
→ анализ и аргументация

ДРЕВНИЙ ВОСТОК
→ фон, не презюмируемый источник Бытия
```

### 2.2. Контроль качества источника

Каждая находка получает один из статусов:

```text
A — первичный текст / критическое издание / официальный facsimile
B — полная академическая монография или статья
C — полный конфессиональный комментарий с аргументацией
D — диссертация / repository manuscript
E — надёжный библиографический или издательский след
F — рецензия / abstract / preview
HOLD — популярный пересказ без достаточной документации
```

### 2.3. Контроль доступа

```text
FULL OPEN PDF
FULL HTML
BORROWABLE / CONTROLLED DIGITAL
PREVIEW ONLY
METADATA ONLY
PAYWALLED
NOT FOUND
DUPLICATE OF EXISTING CORPUS
```

Нельзя писать «полный источник найден», если доступна только landing page или abstract.

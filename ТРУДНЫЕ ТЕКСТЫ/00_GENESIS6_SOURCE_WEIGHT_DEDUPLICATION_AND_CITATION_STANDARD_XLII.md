# Бытие 6: стандарт веса источников, дедупликации и цитатного контроля

**Дата:** 24 июля 2026 года  
**Статус:** `MARATHON-XLII / 00-CANONICAL-METHOD / SOURCE-WEIGHT / DEDUPLICATION / CITATION-AUDIT / NO-NUMBER-THEATER / PRIMARY-SOURCE-FIRST`

---

# 1. Причина стандарта

В ходе марафона были созданы манифесты на 52, 67 и 68 материалов. Они полезны как журнал проверок, но число может создавать ложное впечатление, будто:

- 68 ссылок автоматически сильнее 8 первичных источников;
- два цифровых дубля одной книги являются двумя независимыми свидетелями;
- издательская аннотация равна прочитанной статье;
- популярная страница равна критическому изданию;
- несколько переводов являются несколькими независимыми греческими рукописями.

Этот стандарт запрещает подобную арифметику.

---

# 2. Главный принцип

```text
КОЛИЧЕСТВО ССЫЛОК
≠ ВЕС ДОКАЗАТЕЛЬСТВА

ВЕС ДОКАЗАТЕЛЬСТВА
= БЛИЗОСТЬ К ПЕРВИЧНЫМ ДАННЫМ
+ КАЧЕСТВО МЕТОДА
+ НЕЗАВИСИМОСТЬ СВИДЕТЕЛЬСТВ
+ ТОЧНОСТЬ ПРИМЕНЕНИЯ К ТЕЗИСУ
```

Один официальный снимок рукописи может иметь больший вес для чтения буквы, чем десятки вторичных пересказов.

Одна полная грамматическая статья может иметь больший вес для синтаксиса, чем двадцать популярных комментариев.

# 3. Уровни источников

## Tier 0 — первичный материальный объект

Примеры:

- изображение рукописи;
- официальный цифровой факсимиле;
- физически сохранившиеся чернила;
- древняя надпись или фрагмент.

Использовать для:

- букв;
- строк;
- лакун;
- порядка текста;
- материального состояния.

Не использовать один снимок без палеографической компетенции для самоуверенного нового чтения против критических редакторов.

## Tier 1 — критическое издание / дипломатическая публикация

Примеры:

- ECM;
- NA28 / UBS;
- DJD;
- официальная транскрипция Qumran Digital;
- научное издание древнего текста с аппаратом.

Использовать для:

- принятого текста;
- вариантов;
- обозначения восстановлений;
- редакторских решений.

## Tier 2 — полная рецензируемая монография, комментарий или статья

Условие:

- прочитан релевантный раздел или полный текст;
- позиция проверена в контексте;
- известна страница / раздел.

Использовать для:

- аргументации;
- истории исследования;
- грамматики;
- интертекстуальности;
- альтернативных моделей.

## Tier 3 — официальный abstract, publisher preview, review

Использовать только для:

- установления существования работы;
- основной заявленной гипотезы;
- библиографических данных;
- решения, нужно ли искать полный текст.

Не использовать для:

- подробных аргументов, отсутствующих в аннотации;
- приписывания автору выводов, которых abstract не формулирует;
- цитирования страниц, которых не видели.

## Tier 4 — переводческие примечания и качественные справочные ресурсы

Примеры:

- NET notes;
- официальный перевод с комментариями;
- академический словарь;
- грамматический справочник.

Полезны для:

- картирования вариантов перевода;
- быстрого выявления проблемы;
- лексического контроля.

Они не заменяют первичный греческий / арамейский текст.

## Tier 5 — популярная экспозиция, проповедь, блог

Использовать для:

- истории современной рецепции;
- выявления распространённой доктринальной формулы;
- проверки того, как тезис объясняется аудитории.

Не использовать как главный фундамент спорного текстологического или исторического вывода.

# 4. Метки глубины чтения

Каждый источник в манифесте получает одну из точных меток:

```text
FULL-BOOK-READ
→ ПРОЧИТАНА ВСЯ КНИГА

RELEVANT-CHAPTER-READ
→ ПРОЧИТАНА ЦЕЛАЯ РЕЛЕВАНТНАЯ ГЛАВА / СЕКЦИЯ

TARGETED-PDF-PASS
→ ПРОВЕДЁН ПОИСК ПО ПОЛНОМУ PDF,
  ПРОЧИТАНЫ НАЙДЕННЫЕ ФРАГМЕНТЫ И ИХ КОНТЕКСТ

ARTICLE-FULL-TEXT-READ
→ ПРОЧИТАНА ВСЯ СТАТЬЯ

ABSTRACT-ONLY
→ ДОСТУПНА ТОЛЬКО АННОТАЦИЯ

REVIEW-ONLY
→ ПОЗИЦИЯ ИЗВЕСТНА ЧЕРЕЗ РЕЦЕНЗИЮ

BIBLIOGRAPHIC-ONLY
→ УСТАНОВЛЕНЫ ТОЛЬКО МЕТАДАННЫЕ

POPULAR-POSITION-CONTROL
→ ПРОВЕРЕНА СОВРЕМЕННАЯ ПОПУЛЯРНАЯ ФОРМУЛА
```

Запрещено заменять `TARGETED-PDF-PASS` словом «полностью изучено».

# 5. Дедупликация

## 5.1. Один интеллектуальный труд — один источник

Следующее считается одним источником:

- оригинальный PDF и его дубли с `(1)`, `(2)`, `(3)`;
- EPUB и конвертированный PDF одной редакции;
- издательская страница, DOI-запись и ResearchGate-record одной статьи;
- один комментарий в разных цифровых библиотеках;
- один и тот же перевод на BibleGateway и YouVersion.

Разные URL могут считаться разными **контрольными точками доступа**, но не разными независимыми интеллектуальными свидетелями.

## 5.2. Разные редакции

Новая существенно переработанная редакция может считаться отдельной редакционной единицей, но необходимо указать:

- год;
- издание;
- что именно изменено;
- используется ли она независимо или как обновление прежней версии.

## 5.3. Сборники комментариев

BibleHub или подобный агрегатор:

- одна веб-страница контроля;
- отдельные исторические комментарии внутри могут учитываться как самостоятельные авторы только при чтении их собственного текста и точной атрибуции;
- агрегатор не превращает десять кратких выдержек в десять полностью прочитанных книг.

# 6. Независимость свидетельств

Перед фразой «несколько независимых источников» проверить:

1. Не цитируют ли они один и тот же ранний комментарий?
2. Не зависят ли все переводы от одной критической редакции?
3. Не повторяют ли статьи один и тот же восстановленный текст Milik?
4. Не являются ли разные сайты зеркалами одной публикации?
5. Не принадлежит ли вывод одной школе и одной цепочке цитирования?

Правильная формула:

> «Несколько современных авторов принимают эту позицию».

Не всегда равна:

> «Несколько независимых линий доказательства подтверждают эту позицию».

# 7. Цитатный аудит

Для каждого важного утверждения хранить:

```text
CLAIM
→ ЧТО ИМЕННО МЫ УТВЕРЖДАЕМ

SOURCE
→ КАКОЙ ИСТОЧНИК ЭТО ПОДДЕРЖИВАЕТ

LOCATION
→ СТРАНИЦА / РАЗДЕЛ / СТРОКА / СТИХ

EVIDENCE TYPE
→ ПРЯМОЙ ТЕКСТ / РУКОПИСЬ / РЕКОНСТРУКЦИЯ / МНЕНИЕ АВТОРА

OUR USE
→ ЦИТАТА / ПАРАФРАЗ / ИНФЕРЕНЦИЯ

LIMIT
→ ЧЕГО ИСТОЧНИК НЕ ДОКАЗЫВАЕТ
```

Запрещено:

- использовать ссылку на книгу, если релевантное место не найдено;
- цитировать автора по пересказу без пометки;
- приписывать статье вывод из собственной inference;
- ставить одну ссылку после абзаца с пятью тезисами, если она поддерживает только один.

# 8. Правило 40+ / 50+ материалов

Когда пользователь просит пройти 40+ или 50+ материалов, задача выполняется в два слоя:

## Слой A — широкий обзор

- обнаружить работы;
- классифицировать позиции;
- проверить метаданные;
- выявить дубли;
- определить приоритетные полные тексты.

## Слой B — глубокое ядро

- выбрать первичные тексты;
- выбрать 5–15 главных научных работ;
- прочитать релевантные разделы;
- построить аргумент из данных;
- использовать остальные материалы как контроль охвата, а не как голосование.

Публикационный вывод строится на слое B.

# 10. Минимальное ядро для каждой публикации

Перед выпуском спорной статьи требуется:

1. канонический оригинальный текст;
2. актуальный критический текст и аппарат, если есть значимый вариант;
3. первичный древний параллельный текст;
4. один или несколько manuscript controls;
5. минимум два сильных современных комментария разных подходов;
6. главная конкурирующая позиция в её сильнейшей форме;
7. собственная посвидетельная экзегеза;
8. claim matrix;
9. финальный citation audit;
10. проверка по master authority index.

# 1. Назначение

Этот ledger является обязательным промежуточным слоем между исследовательскими owners и публикационными текстами Статей 6–9.

Для каждого значимого тезиса он фиксирует:

1. точную публикационную формулировку;
2. тип доказательства;
3. первичный текст или рукописный объект;
4. основной научный контроль;
5. точный локус;
6. степень уверенности;
7. границу вывода;
8. место использования в публикационной статье.

Иерархия:

```text
КАНОНИЧЕСКИЙ ТЕКСТ / РУКОПИСЬ
→ ПЕРВИЧНОЕ ДОКАЗАТЕЛЬСТВО

КРИТИЧЕСКОЕ ИЗДАНИЕ / ПОЛНЫЙ КОММЕНТАРИЙ / СТАТЬЯ
→ КОНТРОЛЬ ЧТЕНИЯ И АРГУМЕНТА

SOURCE MANIFEST / ПОПУЛЯРНАЯ СТРАНИЦА
→ НЕ НЕСЁТ ОСНОВНОЙ ТЕЗИС
```

# 2. Система обозначений

- `TEXT` — прямой канонический текст.
- `MS` — материальный рукописный свидетель.
- `TC` — текстологический вывод.
- `LEX` — лексико-синтаксический вывод.
- `CTX` — контекстуальный вывод.
- `INT` — интертекстуальная / литературная связь.
- `HIST` — история традиции и рецепции.
- `THEOL` — канонико-богословский синтез.

Уверенность:

- `EXPLICIT / CERTAIN`;
- `HIGH CONFIDENCE`;
- `PROBABLE`;
- `POSSIBLE`;
- `OPEN`;
- `NOT STATED / FALSE INFERENCE`.

`ad loc.` означает раздел комментария непосредственно к указанному стиху; для комментария это точный содержательный локус, даже если печатная пагинация зависит от цифрового издания.

# Серия Быт. 6 / Енох / Иуда / Пётр: stop-search, готовность к публикации и triage новых источников

**Дата:** 23 июля 2026 года  
**Статус:** `DEEP-PASS-XXVIII-J / STOP-SEARCH / PUBLICATION-READINESS / SOURCE-TRIAGE / ANTI-INFINITE-RESEARCH`

## 1. Проблема

Исследовательский корпус уже достаточно велик, чтобы создать новую опасность:

```text
каждый найденный комментарий
→ новый файл
→ новая формулировка
→ конкурирующий итог
→ статья никогда не завершается
```

Поэтому новый источник оценивается не по принципу «интересно», а по вопросу:

> Какую незакрытую доказательную функцию он выполняет?

# 2. Triage каждого нового источника

## Шаг 1. Это первичный или вторичный материал?

```text
P — canonical/manuscript/ancient primary
E — critical edition/apparatus
M — major monograph/commentary
A — specialised article
R — reception source
O — overview/review
H — popular/HOLD
```

## Шаг 2. Есть ли полный доступ?

```text
FULL VERIFIED
PARTIAL VERIFIED
PREVIEW
ABSTRACT ONLY
METADATA ONLY
UNVERIFIED COPY
```

## Шаг 3. Какой вопрос он владеет?

Источник обязан быть назначен одному основному вопросу:

1. referent `בני האלהים`;
2. Быт. 6:4/Нефилимы;
3. Иуда/2 Петра;
4. 1 Петра 3;
5. 1 Енох/Giants manuscripts;
6. канон/reception;
7. метод/авторство.

Если источник нельзя назначить, он, вероятно, не нужен в основном корпусе.

## Шаг 4. Какой тип новизны?

```text
T — новый текстовый вариант
S — новый синтаксический анализ
L — новый лексический корпус
C — новый канонический intertext
H — новый исторический первичный свидетель
P — лучший представитель позиции
M — новый механизм/модель
B — только новая библиография
D — duplicate
```

## Шаг 5. Способен ли изменить публикацию?

### Tier 1 — меняет вывод

- новый реальный Hebrew/Greek variant;
- первичный текст, опровергающий историю позиции;
- аппарат, меняющий чтение;
- сильный аргумент, не представленный ни одной существующей моделью.

### Tier 2 — меняет формулировку/уверенность

- новый лучший представитель;
- уточнение датировки;
- оригинальный язык ранее известной цитаты;
- рукописный контроль восстановления.

### Tier 3 — укрепляет сноску

- ещё один комментарий с тем же аргументом;
- новый язык той же позиции;
- поздняя reception без нового тезиса.

### Tier 4 — библиографический шум

- повторное summary;
- популярная книга без первичных страниц;
- AI compilation;
- duplicate PDF;
- новая формулировка старого довода без новой экзегезы.

# 9. Saturation rule

Исследовательская семья считается насыщенной, если есть:

```text
1 PRIMARY ANCIENT WITNESS
+ 1 CLASSICAL EXEGETE
+ 1 MODERN SPECIALIST
+ 1 STRONG OPPONENT
+ 1 RESPONSE WITH CONCESSION
```

После насыщения новый эквивалентный источник:

- идёт в bibliography;
- не создаёт новый research file;
- не расширяет публичную статью;
- может заменить более слабую сноску, но не добавляется рядом автоматически.

---

# 10. Правило языкового разнообразия

Язык сам по себе не является новизной.

Немецкий, еврейский, французский, португальский или сирийский источник повышается в основном корпусе, если он:

1. является оригинальным первичным текстом;
2. представляет независимую школу;
3. содержит новый аргумент;
4. является лучшим владельцем позиции;
5. исправляет англоязычный пересказ.

Иначе он помещается в multilingual bibliography.

---

# 11. Правило новых пользовательских загрузок

После каждой новой пачки файлов:

1. SHA/duplicate check;
2. full/partial/review classification;
3. article owner;
4. novelty tier;
5. claim changed? yes/no;
6. exact page extraction;
7. supersession note if needed.

Не создавать отдельный файл на каждый PDF. Один тематический ingest-файл может обрабатывать несколько источников одной семьи.

## 14. Итог

> С этого момента ценность нового источника определяется не количеством страниц и не редкостью языка, а тем, закрывает ли он конкретный доказательный пробел. Статья 1 достигла насыщения и должна редактироваться. Остальные статьи получают только узкие тематические поиски. Это предотвращает превращение Research в бесконечный склад и сохраняет различие между доказательной базой, историей исследования и публичным текстом.

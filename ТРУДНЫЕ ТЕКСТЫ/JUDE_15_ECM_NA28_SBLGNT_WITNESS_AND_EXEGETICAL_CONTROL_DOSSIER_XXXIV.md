# Иуд. 15 — `πᾶσαν ψυχήν` или `πάντας τοὺς ἀσεβεῖς`: ECM, свидетели и экзегетический контроль

**Дата:** 24 июля 2026 года  
**Статус:** `ARTICLE-6-TEXTUAL-DOSSIER / ECM-CONTROLLED-BUT-NOT-FULL-APPARATUS / NA28 / SBLGNT / REPRESENTATIVE-WITNESSES / CBGM-PENDING / NO-THEOLOGICAL-CONVENIENCE-CHOICE`

---

# 1. Узел

После слов:

```greek
ποιῆσαι κρίσιν κατὰ πάντων
καὶ ἐλέγξαι ...
```

текстовая традиция сохраняет несколько объектов глагола `ἐλέγξαι`.

## Чтение A

```greek
πᾶσαν ψυχήν
```

> «всякую душу / каждого человека».

## Чтение B

```greek
πάντας τοὺς ἀσεβεῖς
```

> «всех нечестивых».

## Чтение C

```greek
πάντας τοὺς ἀσεβεῖς αὐτῶν
```

> «всех нечестивых их / всех их нечестивых» — расширенная форма.

Вопрос не является второстепенным для синопсиса с 1 Енох 1:9, поскольку объект обличения различается в греческих ветвях.

---

# 2. Что установлено по критическим изданиям

## 2.1. ECM / NA28

Второе переработанное издание ECM Catholic Letters лежит за текстом Католических посланий NA28. В Иуд. 15 основная строка ECM/NA28 читает:

```greek
πᾶσαν ψυχήν
```

## 2.2. SBLGNT

SBLGNT печатает:

```greek
πάντας τοὺς ἀσεβεῖς
```

Его сравнительное приложение прямо фиксирует отличие ECM:

```text
SBLGNT
→ πάντας τοὺς ἀσεβεῖς

ECM
→ πᾶσαν ψυχήν
```

## 2.3. Westcott–Hort и Tregelles

Также поддерживают форму без `αὐτῶν`:

```greek
πάντας τοὺς ἀσεβεῖς
```

## 2.4. Византийская / большинство-традиция

Часто имеет расширение:

```greek
πάντας τοὺς ἀσεβεῖς αὐτῶν
```

# 4. Внутренняя вероятность `πᾶσαν ψυχήν`

Положительные аргументы:

1. выражение неожиданно и потому могло быть заменено более понятным объектом;
2. оно напоминает семитический универсальный объект — «всякая душа / всякая плоть»;
3. создаёт объяснимую связь с греческим `πᾶσαν σάρκα` в Panopolitanus;
4. переписчик мог заменить редкое выражение повторяющимся в контексте `ἀσεβεῖς`;
5. ранняя поддержка `𝔓72` и `א` требует серьёзного веса.

Ограничения:

- `ψυχή` может выглядеть как греческая адаптация, а не ближайшая форма енохического текста;
- широкая древняя поддержка альтернативы не позволяет решать вопрос только lectio difficilior;
- точный аргумент ECM требует прямого контроля тома и CBGM.

---

# 5. Внутренняя вероятность `πάντας τοὺς ἀσεβεῖς`

Положительные аргументы:

1. естественно продолжает повторение `ἀσέβεια / ἀσεβέω / ἀσεβεῖς`;
2. соответствует основной риторике Иуды против нечестивых;
3. имеет широкую и древнюю греческую поддержку;
4. может стоять за расширением с `αὐτῶν`;
5. Timo Flink специально защищал это чтение против решения ECM/NA.

Ограничения:

- именно контекстуальная лёгкость могла вызвать гармонизацию;
- повторение «нечестивых» может быть вторичным риторическим сглаживанием;
- широкая традиция способна восходить к раннему общему предку и не равна множеству независимых решений.

# 6. Влияние на 1 Енох 1:9

## Если первоначально `πᾶσαν ψυχήν`

```text
JUDE
→ всякую душу

PANOPOLITANUS
→ всякую плоть
```

Это может отражать:

- отличающуюся греческую редакцию;
- переводческую адаптацию семитического объекта;
- Иудину риторическую редакцию;
- иной Vorlage.

## Если первоначально `πάντας τοὺς ἀσεβεῖς`

Это сильнее совпадает с повторяющейся судебной категорией нечестивых и может отражать:

- другую греческую редакцию Еноха;
- Иудино тематическое уточнение;
- более раннюю форму, позднее заменённую универсальным объектом;
- адаптацию к адресатам послания.

## Общий итог


# 7. Связь с Timothy Lee 2025

Lee предлагает кумулятивную модель отличающейся ревизованной греческой формы Еноха. Вариант объекта должен быть встроен в модель, но не решает её один.

```text
πᾶσαν ψυχήν
→ может усиливать различие с Panopolitanus
→ требует объяснения перевода/ревизии

πάντας τοὺς ἀσεβεῖς
→ может усиливать тематическую адаптацию
→ также допускает отличающийся Greek Vorlage
```

Следовательно, гипотеза Lee не должна строиться так, будто один объект бесспорен.

# 11. Проектный verdict

> Иуд. 15 имеет реальную раннюю развилку: ECM/NA28 читает «обличить всякую душу», тогда как SBLGNT, Westcott–Hort, Tregelles и THGNT предпочитают «обличить всех нечестивых»; позднейшая традиция часто добавляет «их». Первое чтение поддержано `𝔓72` и Синайским кодексом, второе — широким рядом древних свидетелей, включая A, B, C и Ψ. Ни подсчёт рукописей, ни принцип «труднейшее чтение» не решают вопрос автоматически. До прямого контроля полного ECM и CBGM проект не объявляет спор закрытым. При обоих чтениях связь Иуд. 14–15 с 1 Енох 1:9 остаётся весьма вероятной.

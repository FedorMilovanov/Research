# RESEARCH — аудит структуры и безопасная очистка для корпуса Реформации

**Фиксация:** 2026-11-04. База до работы: `main@02e1181621c51a5a6a5d865b05e41390b846d963`; GitHub recursive tree: **2 816 entries**, `truncated=false`. Значение относится к количеству объектов дерева (файлы и директории), а **не** к числу уникальных научных работ. Основной `main` защищён; изменения вынесены в одну изолированную ветку `research/reformation-evidence-base-20261104`. Не называть этот аудит полной инвентаризацией всех байтов и внешних архивов.

## Обнаружено

- В каталоге `docs/research/` до работы существовал тематический массив **`atonement/`** (в частности, `02_history_of_atonement_controversies.md`, `15_patristic_and_reformation_misattributions.md`, `27_pan_european_reformed_controversies_and_saumur_condemnation.md`). Это **другое исследование**: оно содержит частичную историю богословских споров и не заменяет независимую историю Реформации XVI века.
- Иные связанные материалы лежат в `1_КОРИНФЯНАМ_11/`, `ИСКУПЛЕНИЕ/`, `TEEN_DOUBLE_LIFE/`, `SOURCE_LIBRARY/`, `SUNO_HYMNS/`, `БИОГРАФИИ/`. Эти файлы являются собственными корпусами, а не кандидатами на «мусор» только по совпадению слов *Reformation / Calvin / Luther*.
- **Прямого исторического корпуса** `docs/research/reformation/` и файла с точным именем `2026-11-03-lordchrist-reformation-source-ledger.md` в проверенном дереве `main` не было. Поэтому создан отдельный каталог с устойчивой навигацией, а не дублирование существующего кейса.
- [Загруженная пользователем исследовательская карта](source-ledger-2026-11-03-original.md) содержит датированные выводы и ссылки, но **прямо описывает проверку 12 файлов другого агента лишь как оценку досье**, без самих 12 файлов. Во втором пользовательском приложении — история переписки, а не машинный архив полных результатов всех агентских сеансов. **Полный исходный пакет недоступен.**
- В исходной карте смешаны уровни верификации: достоверно названные критические издания, реальные листы XVI века, поздние переводы, пересказы, неосмотренные изображения и выводы без собственной колляции. Поэтому не пытались «очистить» её уничтожением строк: создан [реестр утверждений](03_claim_verification_register.md) с поправками и ограничениями.

## Что очищено реально

1. **Устранён навигационный вакуум:** один самостоятельный каталог `docs/research/reformation/`, один README и один машиночитаемый реестр; материалы других корпусов не копировались сюда целиком.
2. **Нормализованы классы свидетельств:** `A1/A2/A3/B1/C/D` и независимые `accessState`, `locatorState`, `rightsState`, `publicationState`; исторические пояснения перестали называться «проверенным первоисточником» только потому, что ведут на скан.
3. **Убрана логическая путаница из нового изложения** (оригинал остаётся нетронутым): дверь vs письмо; текст 1517 vs исповедание 1530; локальные права протестующих vs свобода всех; авторское мнение vs цитата; OCR vs визуальная сверка; архивная карточка vs оцифрованная рукопись; поздняя грамотность vs XVI век.
4. **Сведена библиография в один читальный зал** и обозначен порядок законного приобретения. Не создано повторяющихся кратких отчётов, новой копии искажённого текста, не заведено отдельных ветвей для каждой темы.
5. **Дубликаты нового корпуса:** нет; оригинал вложения хранится единожды, ссылки на него идут из связанных документов.

**Деструктивных удалений: 0.** Это осознанное решение: нельзя назвать «мусором» исследовательские досье без проверки связей, истории и прав на хранимые материалы. Очистка этого этапа — **дедупликация схемы, утверждений и ссылок**, а не массовое удаление данных.

## Что потребует доказательной очистки позднее

| Объект | Риск | Предписанное безопасное действие |
| --- | --- | --- |
| Входящие файлы прежних агентов (упомянутые 12) | История исследований могла остаться вне Git / на другом устройстве | Получить список имён, SHA256, каталоги и права; сделать `ACQUIRED` или `NOT_ACQUIRED`, не сочинять |
| Старые `research`-записи по частным темам | Непроверенная терминология и повторы | Понять authority, ссылки и потребителей; редакционно пометить `HISTORICAL/SUPERSEDED/CONFLICT`, не удалять |
| Исторические OCR, сканы, фото и AI-картинки | Размеры, авторское право, неверная атрибуция | Сначала provenance + лицензия + точный hash; разрешить только обоснованные экземпляры; исключить бинарные зеркала из Git |
| Гипотетические `tmp`, выгрузки, `cache`, `downloads` | Могут быть артефактами другого рабочего процесса или единственной копией источника | Сначала read-only inventory, поиск ссылок, срок хранения, подтверждённая восстановимость; затем точный список к удалению |
| `SOURCE_LIBRARY`, `atonement`, другие corpus authority | Общая root authority и CI-зависимости | **Не удалять в рамках этого тематического задания** |

## Недостающие сведения для полной реконструкции

- Сами **12 файлов** из старого межагентского досье: имена, издательские выходные данные, конкретные снимки, черновые колляции и замечания.
- Экспорты длительных сессий двух агентов, если в них было больше, чем итоговая карта и история команд. Не объявлять их восстановленными на основе реплик в переписке.
- Подлинные фотоматериалы и условия их использования, если позже возникнет задача иллюстрировать результаты. Ни в этом PR, ни в корпусе изображения не генерируются и не публикуются.
- Полные изображения некоторых старопечатных памятников и критические книги, доступные только через библиотечные подписки.

## Отдельная проверка перед любым будущим удалением

`Delete gate` (все пункты обязательны):

1. Объект идентифицирован по **точному пути, размеру, хешу и текущему commit**.
2. Все ссылки и импорты в RESEARCH просмотрены; доказано, что он не часть действующей authority, реестра, теста или обратимого исторического свидетельства.
3. Есть заменяющая каноническая копия с проверенным полным содержимым (либо объект по природе пересоздаваемый).
4. Установлена правомерность удаления и сохранённая точка восстановления.
5. Подготовлен **отдельный точечный diff**, не общий скрипт с маской `*reform*`, `*archive*` или `*old*`.
6. При отсутствии хотя бы одной проверки — **не удалять**.

## Общий протокол для обоих рецензентов

1. Читать **читательский текст** целиком; за ключевой формулировкой открыть соответствующий `## Источниковедческий аппарат`, реестр утверждений, оригинальное издание и исследовательское досье. Нельзя оценивать лишь по «сильной» фразе заголовка или скриншоту каталога.
2. Каждое существенное замечание записать в формате **глава/подзаголовок → точная спорная формулировка → тип (факт, атрибуция, дата, перевод, причинность, богословская интерпретация, право, жанр) → точный источник (автор/издание/лист или пункт/URL) → контраргумент → рекомендуемая замена → статус доказательства**. Указывать, читался ли реальный лист, редакционная транскрипция, перевод, обзор либо только каталог.
3. Вердикт по каждой записи: **PASS_WITH_SCOPE** (достаточно для этой осторожной формулы), **CORRECTION_REQUIRED** (ошибка с точной заменой), **EVIDENCE_REQUIRED** (открытый оригинал/протокол/дата), **INTERPRETATION_DISPUTED** (обе позиции отразить), **OUT_OF_SCOPE** (другой корпус/не решает вопрос). Отсутствие замечаний не является лицензией на изображения, цитаты, перевод или издательским одобрением.
4. Внешнюю рецензию нельзя имитировать агентом, запуском тестов или этой памяткой. Отзывы должны иметь **имя/компетенцию реального проверяющего, дату, конкретные фрагменты и источник**, при согласии на сохранение. Конфиденциальные переписки и рукописи без прав не выкладывать в публичный Git.
5. Запрещены новые «очевидные» атрибуции, выдуманные дословные цитаты, статистика без популяции/методики, незаметное исправление доказательных меток и принудительная гармонизация конфессий. `STOP_DISCOVERY` для двух безрезультатных повторов одной гипотезы; критически новая Tier 1 находка не блокируется искусственно.

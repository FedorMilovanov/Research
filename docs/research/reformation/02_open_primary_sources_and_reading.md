# Реформация XVI века — открытый читальный зал и программа приобретения

**Цель:** дать исследователю доступ к текстам эпохи в разных редакциях, не затягивая защищённые авторским правом PDF в Git. **Дата новой веб-проверки:** 2026-11-04. Не все записи прочитаны целиком: вид доступа указан по каждому пункту. Этот файл — библиографический каталог, а не готовая цитатная подборка.

## Как пользоваться

- **Открыть / читать** означает, что обнаружена общедоступная страница; это **не** означает просмотр всей книги или подтверждение всех формулировок.
- **Скачать** означает, что на странице предложен PDF, XML, EPUB или изображения; фиксируем тип. Никакие внешние файлы и картинки **не импортированы автоматически** в репозиторий.
- Классификация оригинального участника: **A1** для документа, написанного участником эпохи (включая позднюю критическую транскрипцию с явно указанным оригиналом). **A3** для официального институционального текста, **B1** для академической реконструкции; точность цитаты определяется отдельно.
- Современная редакция A1 не становится «автографом»; каталогизированная архивная запись A2/A3 не подтверждает точный вид рукописи, пока объект не получен.
- Статус локатора: `EXACT_LOCATOR_VERIFIED` только после сверки *конкретного* раздела с доступным текстом; общая ссылка = `COARSE_LOCATOR_ONLY`. Не путать с `rightsState`.

## Учебные фонды для систематического поиска

- [Bodleian / Oxford — каталог Early Modern primary sources](https://libguides.bodleian.ox.ac.uk/earlymodernhistory/primarysources): часть ресурсов институциональная/платная; проверять доступность каждого отдельно.

- [Emory Pitts Theology Library, Digital Collections](https://digital.pitts.emory.edu/s/digital-collections): каталог подлинных книг XVI века и разрешённые цифровые копии.
- [German History in Documents and Images](https://germanhistorydocs.org/): переводы первичных текстов и вводные исследования; переводы не выдавать за оригиналы.
- [Digitale Editionen der Europäischen Religionsfrieden / TU Darmstadt](https://tueditions.ulb.tu-darmstadt.de/): немецкие тексты политико-религиозных документов.
- [The Library of Congress — Martin Luther: Priest, Heretic, and Outlaw](https://guides.loc.gov/martin-luther-priest-heretic-outlaw): современный музейный путеводитель и доступ к коллекции.

## Автоматическая структурная приёмка (без изменений файлов)

Запуск при наличии **Python 3.9+** из корня `Research`:

```bash
python docs/research/reformation/validate_corpus.py
```

[Исходный код валидатора](validate_corpus.py) не требует сторонних библиотек, **ничего не скачивает, не удаляет и не изменяет**. Он проверяет: исходную пользовательскую карту через Git blob SHA; JSON и разрешённые `evidenceClass/accessState/locatorState/rightsState/publicationState/HOLD`; уникальные ID, порядок `Cxx`, существование относительных ссылок, соответствие утверждений определённым ID; отсутствие фиктивных SHA-256 у нескачанных архивных копий. Добавлены **регрессионные проверки семантически опасных связей**: статья Becker—Woessmann не может снова стать работой о Варшавской конфедерации; датский репринт обязан отмечать источник **1542**, варшавская запись — обследование **2016**.

**Граница валидатора:** PASS подтверждает только структурную и договорную непротиворечивость; он **не доказывает историческую истинность, авторские права или личный просмотр архивного подлинника**. Восстановление таких доказательств — отдельная источниковедческая задача.

## Границы корпуса и метод

- **Период:** долгий предреформационный контекст и прежде всего 1517–1600 годы; отдельные предыстории и последствия маркируются по времени.
- **Направления:** германская, швейцарская, реформатская, английская, радикальная Реформация, католическая реформа, политико-социальные последствия.
- **Позиция:** исследование может разбирать протестантские догматические оценки как *конфессиональный взгляд*, но **исторические утверждения** проверяются независимо от этой позиции.
- **Без темы Иуды**, без вмешательства в VCM / Telegraph / Telegram / VK / очереди / `media` / `publisher` / `workflow`.
- **Не пересоздавать историю агентов:** доступны только загруженная исходная карта и объясняющая история переписки. Упомянутые в карте 12 исходных файлов другого агента не получены.
- **Доказательства:** соблюдать [корневую evidence-policy](../../../data/repository-evidence-policy-v2.json) и [AGENT_RULES](../../../AGENT_RULES.md). `A1/A2/A3/B1/C/D` — классы источников, не степень уверенности. `EVIDENCE_HOLD`, `LOCATOR_HOLD`, `ARCHIVE_HOLD`, `RIGHTS_HOLD`, `PUBLICATION_HOLD` — независимые ограничения.
- Для каждой цитаты необходимы идентифицированная редакция, точный локатор, контекст, проверка допуска. **Ни одна цитата в этом корпусе не имеет автоматического quote-safe/publication approval.**
- Каталожная запись ≠ полный объект; цифровая транскрипция ≠ сверка с первопечатным листом; ссылка на PDF ≠ проверенные байты. Русские передачи иностранных текстов — редакционные, пока не закреплены по свидетелю и странице.

## Протокол пополнения

1. Проверить SHA актуального `main`, этот README и действующую корневую authority.
2. Найти точный источник, зафиксировать создателя, дату, язык, редактора, издателя, сигнатуру/VD16/WA и URL.
3. Различать оригинал, поздний перепечатанный текст, перевод, репродукцию и исследовательский комментарий.
4. Зафиксировать `accessState`, `locatorState`, `rightsState`, `publicationState` и HOLD.
5. Сопоставить трудные цитаты с изображением страницы, а если требуется — с альтернативным печатным свидетелем.
6. Интегрировать в имеющееся досье; **не плодить отчёты/ветви на каждый источник**.
7. Полнотекстовые материалы третьих лиц не копировать в публичный репозиторий без проверки прав. Читальный зал содержит ссылки на разрешённые внешние копии; загрузка для личного чтения выполняется отдельно с проверкой лицензий и условий.

**Фактический результат этого прохода:** исходная карта сохранена, выполнена новая выборочная проверка первичных документов и научных описаний, создан план продолжения. Это **начальная структурированная база**, не завершённая монография и не полная реконструкция прежних агентских исследований.

## Мини-очередь получения
- **Ключевой первичный объект:** есть/нет, место, права, что прочитано.
- **Критический независимый контекст/оппонирующая позиция:** есть/нет, точный локатор.
- **Если книга закрыта:** один REQUEST_USER с автором/годом/страницами/зачем нужна; не повторять поиски.
- **Если видео:** одно нужное официальное видео/интервал, DISCOVERED ≠ WATCHED_WITH_AUDIO.
- **Если доступны только ссылки:** оставить ссылки, но не писать ACQUIRED/READ.
- **Google Drive/локальный архив:** использовать существующий, записать file ID/hash только после фактического сохранения; не создавать новый источник истины.

## Работа и завершение
1. FRAME: сформулировать вопрос и ответ без скрытой смены темы.
2. DISCOVER/READ: обычно один первичный проход и один адресный; дополнительные исследования только если меняют claim по Tier 1/2.
3. DRAFT: написать **целый текст** с переходами, не пачку разрозненных выдержек.
4. REVIEW: проверки голоса, контекста, числа, точного цитирования, противоположного довода и прав.
5. DECIDE: редакторское решение, оставшиеся HOLD, отдельный публикационный допуск.

**STOP:** после двух безрезультатных адресных проходов — остановить бессрочный поиск и выбрать более осторожный текст, точный запрос пользователя или локальный блокер. Не блокировать законченную статью из-за Tier 3/4 дополнений.

# Джон Гилл: матрица доступа к корпусу — 120+ источниковых единиц

> **Дата прохода:** 2026-07-23  
> **Назначение:** превратить накопленный список ссылок в управляемый исследовательский корпус.  
> **Единица учёта:** отдельная книга, том, диссертация, статья, памфлет, факсимиле, архивная запись или самостоятельный полнотекстовый раздел.  
> **Важно:** количество источниковых единиц не равно количеству доменов. Один официальный каталог может вести к десяткам самостоятельных томов; каждый том учитывается отдельно только тогда, когда у него есть самостоятельная исследовательская задача.

## 0. Система статусов

| Код | Значение |
|---|---|
| **A1** | официальный факсимильный PDF / скан первоисточника |
| **A2** | официальный или устойчивый полный машинный текст первоисточника |
| **A3** | официальная библиографическая запись без открытого полного файла |
| **B1** | официальный полный PDF академической диссертации / статьи |
| **B2** | официальное описание, abstract и оглавление; PDF закрыт или нестабилен |
| **B3** | легально опубликованный журнальный PDF на профильном архиве |
| **C1** | конфессиональная транскрипция; использовать после сверки со сканом |
| **C2** | неофициальное зеркало / поисковый машинный текст; только для навигации |
| **X** | источник пока не добыт или не локализован до страницы |

### Правило цитирования

1. Для прямой цитаты предпочтителен **A1**.
2. **A2** допустим после двойной сверки с другим изданием.
3. **A3/B2** подтверждают существование и метаданные, но не точный текст.
4. **C1/C2** не должны быть единственной опорой спорного утверждения.
5. Если академический автор пересказывает Гилла, всё равно ищется цитируемое место у самого Гилла.

- найдено;
- доступно полностью;
- просмотрено оглавление;
- проверены ключевые главы;
- сверено с первоисточником;
- готово к цитированию.

## 11. Редакционный принцип для серии

Каждое сильное утверждение в статье должно получать одну из маркировок во внутреннем реестре:

- **P** — прямо сказано Гиллом;
- **C** — свидетельство современника;
- **B** — биограф Риппон;
- **H** — вывод современного историка;
- **I** — вывод автора статьи;
- **D** — спор исследователей.

Без такой маркировки фразы типа «Гилл был первым», «Гилл никогда», «Гилл доказал», «конфликт был мнимым» и «его последователи сделали» легко превращают сложную историю в уверенный, но плохо проверяемый нарратив.

> **Вердикт матрицы:** открытого материала достаточно для серьёзной критической серии. Главная проблема теперь не нехватка источников, а дисциплина сплошного чтения, постраничной фиксации и точного разделения первичного текста, свидетельства и историографического вывода.

## 3. Объём работ (конкретно)

### 3.1 Общая карта
- Свести три слоя (ВЗ / НЗ / отцы) + исторический контроль (Дорт, Кальвин, Оуэн) + современного Мюррея (`B1`) в одну таблицу: **тезис → что говорит ВЗ → НЗ → отцы → XVII век → современность → статус (доказано / спорно / не доказано)**.
- По каждому спорному тезису вести competing readings минимум по два, с указанием, какой текст какое чтение поддерживает.
- Отдельно: **оси**, чтобы не смешивать — природа искупления / необходимость / совершенство / объём (extent) / применение / предложение (free offer). Каждый тезис помечать осью.

### 3.2 Конфликт-лист
- Явный список мест, где слои расходятся (например: язык всеобщности у отцов vs реформатская формула; «за многих» vs «за весь мир»; conditional universalism vs particularism).
- Для каждого: в чём именно расхождение (текст, метафора, логический вывод), можно ли снять текстом, или это честное расхождение чтений.
- **Не сглаживать.** Снятое молча расхождение = искажение корпуса. Цель — чтобы читатель серии видел границу дозволенной формулировки.

### 3.3 Серия: состав и оценка
- Отталкиваться от слоёв `01_` (A-foundation / B-extent-and-nuance / C-application / D-reserve) и минимального набора `06_` §3.
- Предложить: сколько статей нужно минимум для непустого hub, сколько — для полного покрытия, и **почему**. Оценка — диапазоном, с указанием зависимости («если НЗ-слой подтвердит X, добавится статья Y»).
- Каждой будущей статье: рабочее название, слой, вопрос, на какие карточки опирается, что должна НЕ утверждать.
- Первая читательская статья — **«Что такое искупление»** (словарь и мотивы, запрет партийного старта). Старт с TULIP запрещён.

### 3.4 Практическое осмысление
- `01_` ст. 8: «Как пастырски не сломать совесть?» — ограниченное не должно звучать как «может быть, крест не для тебя»; всеобщее — как «крест никого сам по себе не спас». Развернуть в конкретные правила тона и формулировок.
- Отдельно: уверенность (assurance), проповедь покаяния и веры, молитва за всех, evangelism, вопрос о «не слышавших», дети, стойкость святых.
- Ключевой принцип: без accomplishment нет application; application не составляет accomplishment. Удерживать обе половины.

### 3.5 Черновики
- Писать от `drafts/01_what-is-atonement.md` дальше по плану. Формат research-черновика: заголовок, STATUS, слой, опорные карточки со ссылками, текст, явный блок «что здесь утверждать нельзя».
- Цитировать только из PD-источников с локатором либо как `B1` с пометкой. Murray (`B1`) — **не** цитировать в публичный продукт: `RIGHTS_HOLD` + `PUBLICATION_HOLD`.
- Для каждой цитаты проверять: есть ли `locatorState` и `rightsState`, не снят ли HOLD.

## 6. Запрещённые формулировки

- «Доказано, что Христос умер только за избранных» и зеркальное «доказано, что за всех». `EVIDENCE_HOLD`.
- «Учение Церкви всегда было…» без списка мест и эпох.
- «Крест ничего не сделал для неспасённых» / «крест сделал всех спасаемыми, но не спас никого» — обе формулы требуют уточнения по оси.
- Карикатуры: «арминиане верят в спасение делами», «кальвинисты не проповедуют евангелие всем».
- «Гарантированно N статей» — счётчик не замораживается; только рабочая оценка.
- Начинать серию с TULIP или с «limited atonement» как заголовка первой статьи.

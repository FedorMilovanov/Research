## Общие правила для всех четырёх

1. **Один authority по теме.** Вопрос «что доказано об искуплении» остаётся за `ИСКУПЛЕНИЕ/00_CURRENT_AUTHORITY_2026-10-07.md`. Под-корпуса имеют свои authority-файлы, но они подчинены корпусному и не могут его «поправлять» молча.
2. **Root не трогать.** `00_RESEARCH_CURRENT_AUTHORITY_2026-08-02.md` — корневой authority репозитория; не менять и не заносить в registry как root.
3. **Не дублировать соседние корпусы.** `Джон Гилл/`, `apostasy/`, `ОТСТУПНИЧЕСТВО/`, `СЕРИЯ СЕРДЦЕ/` — ссылаться, не копировать.
4. **Классы и статусы раздельно.** `evidenceClass` (A1/A2/A3/B1/C/D) ≠ `accessState` ≠ `locatorState` ≠ `rightsState` ≠ `publicationState`. Ссылка, URL и библиографическая запись HOLD не снимают.
5. **`EVIDENCE_HOLD` на «ограниченное искупление доказано» не снимает никто**, без явного решения владельца.
6. **Конфликты не гасить.** Расхождение между слоями заносится в конфликт-лист и в отчёт, а не удаляется правкой.
7. **Git:** одна ветка и один PR на сессию; не `main`, не `.github`, без `force`/`reset --hard`; коммит после каждого шага (≲400 строк); трейлер `Co-authored-by: arena-agent <…>` сохранять.
8. **Отчёт по шаблону:** СДЕЛАНО / ПРОВЕРЕНО / НЕ ПРОВЕРЕНО / СРЕДА / РЕШЕНИЯ САМ / ветка+SHA+PR+CI / что делать владельцу. Ход не закрыт, пока не сделано **и** проверено.

# Инструменты слоя `ot/` (не часть корпуса)

Скрипты, которыми собирались и проверялись карточки 01–13. Держатся в репозитории
потому, что песочница уже трижды теряла `/tmp`, а вместе с ним и проверяемость
карточек. В корпус (`data/ot-corpus-v1.json`) они не входят.

## Зависимости

Скрипты читают локальные клоны источников из `/tmp/arena-scratch/src/`:
`morphhb` (WLC + морфология + лексикон), `sblgnt`, `lxx-swete` (S23),
`First1KGreek` (tlg0527), `LXX-Swete-1930` (S11), `HebrewLexicon`,
`greek_lexica_perseus`, `Swete-1909-LXX`. Клоны не коммитятся: копирайт-статус
зеркал разный (GPL-3.0 / CC BY-SA 4.0 / MIT / PD), сверка — только на месте.

## Файлы

| файл | назначение |
|---|---|
| `ot.py` | слой доступа к источникам: `mt_show`, `mt_lemmas`, `f1k`, `eli`, `s23`, `nt` |
| `qalite.py` | проверка цитат: каждый еврейский/греческий отрезок ≥2 токенов ищется в МТ, LXX (ELI 1930 + F1K Дан. + S23) и SBLGNT; `[A]` — не найден, `[B]` — отличие в один символ |
| `mixcheck.py` | проверка «кириллица внутри греческого/еврейского» и «латиница внутри кириллицы» перед коммитом |
| `triage.py` | то же, что `qalite.py`, но с номерами строк: печатает каждый неаттестованный фрагмент (`file:line`) для поштучной классификации (аппарат, цитата LSJ, порча зеркала, леммная форма) |
| `jsonstyle.py` | сериализация SSOT в его смешанном стиле (`render`, `kv_block`) без пересериализации всего файла |
| `lex.py` | Strong/BDB-выборки по лексемам |
| `bdb_index.py` | оглавление BDB по идентификаторам (`k.cu.ac` и т. п.) |
| `lsj.py` | статьи LSJ по TLG beta-коду |
| `beta.py` | конвертация TLG beta-кода в юникод |

## Запуск

```bash
python3 tools/qalite.py ИСКУПЛЕНИЕ/ot/12_DAN9_SEVENTY_WEEKS.md
python3 tools/mixcheck.py ИСКУПЛЕНИЕ/ot/*.md
```

`qalite.py` строит корпуса лениво и держит их в памяти (пик ~3.9 ГБ): регулярные
выражения по 70-МБ XML не запускать, только `str.find`/`in`.

Реестр результатов повторной проверки карточек 00–16 (2026-10-14) — ключ `qaQalitePass`
в SSOT: 28 строк `[A]` разобраны по классам, ни одна не является стиховой цитатой карточек.

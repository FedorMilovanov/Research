- **ED-06 — переводы.** Все **12 английско-русских пар** собраны и проверены по контрольным суммам, но независимых рецензентских решений **0/12**; для `TR-Q-06`, `TR-Q-07`, `TR-Q-10` подготовлены исправления-кандидаты, не утверждённые как окончательные. [Исходный пакет для рецензента](../supplemental-audits/ED06_EXTERNAL_REVIEW_PACKET_ALL12_2026-11-18.md) · [Актуальные производные кандидаты](../supplemental-audits/ED06_THREE_ENGLISH_WITNESS_TRIANGULATION_2026-11-18.md).
- **ED-08 — архив книги: ЗАКРЫТ для закреплённой ревизии.** [Последняя независимая архивная квитанция 17/17](../../../data/charnock-editorial-book-receipt-v2-20261123-pr629-f18a5e0.json) удостоверяет исходный снимок `f18a5e0410d06f82acd1cbc57054ee025c57ec58`, 992494 байта, с проверенным повторным скачиванием из Google Drive. Архивная приёмка не означает независимую рецензию или допуск публикации.

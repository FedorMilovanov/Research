# План превращения исследовательского материала в биографическую серию о Стивене Чарноке

**Статус:** проект deliverable (e)  
**Источник:** исследование Чарнок, ветка `arena/632a3dec-research`, волна wave40 (2026-10-26), тома 00–17  
**Целевая архитектура:** 10 документов (Введение + 8 частей + Справочник), согласованная в томе 16 §21  
**Ограничение:** публикация остаётся BLOCKED до независимой проверки квитанции (`python scripts/audit_charnock_handoff.py --require-receipt`). План не autorisiert публикацию и не начинает авторство. Статьи не пишутся на этом этапе.

---

## 0. Принципы сборки (неизменные)

1. **Архитектура меняется только с доказательством реальной необходимости и через координатора MAX.** 10-докция утверждена; сокращение или слияние частей — только по отдельному заданию.
2. **Нет механического дублирования со статьёй №2 LordChrist.** Статья №2 — отдельная историко-биографическая статья для LordChrist (PR #971, репозиторий `video-channel-manager`). Десятичастная серия — отдельный проект для сайта «Господь Бог — сила моя». Материал, полезный для обоих, передаётся координатору MAX отдельно с указанием подходящей части серии.
3. **Эпичность через плотность проверенного факта и честные лакуны.** Никакого fictionalization для заполнения пробелов. Лакуны обозначаются явно.
4. **Charnok = English Puritan nonconformist с Presbyterian church connection, NOT Baptist.** Никакого переписывания под современную баптистскую аудиторию.
5. **Gill born after Charnock's death.** Сравнение allowed, но персональная связь/прямое влияние только с документированной цепочкой передачи.
6. **Каждая позиция проверяется по собственному тексту Чарнока.** Не приписывать поздним реформистским systematism автоматически.
7. **Отличать действительную цитату от proven influence.** Цитирование ≠ влияние.

## 3. Этап 3: Подготовка к авторингу (не сам авторство)

### 3.1. Редакционные ориентиры по объёму

Литературная полнота определяется содержанием, а не количеством слов. Отказ от жёстких норм объёма (например, 1800–4500 слов на документ). Каждый документ пишется до раскрытия своей темы, без искусственного растягивания или сокращения.

### 3.2. Формат передачи в авторство

После закрытия всех gates и получения новой квитации передаётся:
- Утверждённый 10-док план с паспортами (§21.1)
- Таблица исключения повторов (§21.2)
- Опорная выборка с локаторами и статусами (BCD-01…40, TXT-01…20, REC-01…08)
- Карта богословских идей с первичными локаторами (deliverable (a))
- Новые значимые находки (deliverable (b))
- Критический аудит плана (deliverable (c))
- Реестр лиц и типизированные связи (том 16 §4)
- Статусы доступа и прав для каждого объекта

Авторские главы на этом этапе: 0. Переводы не готовились.

## 4. Этап 4: Авторство (отдельное задание, не начато)

Начинается только после:
1. Подтверждения квитации (`python scripts/audit_charnock_handoff.py --require-receipt` возвращает `BOUNDED_RESEARCH_COMPLETE`)
2. Отдельного задания пользователя на авторинг или расширение объёма
3. Повторной проверки источников/прав для публикуемых фрагментов

Авторство ведётся строго по паспортам (§21.1), с соблюдением «не обещаем / не утверждаем» границ, с привязкой каждого факта к локатору и статусу доказательств.

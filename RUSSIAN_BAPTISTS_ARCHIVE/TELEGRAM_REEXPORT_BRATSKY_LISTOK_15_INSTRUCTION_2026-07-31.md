## Надёжный маршрут восстановления

1. В Telegram Desktop открыть **Settings → Advanced → Export Telegram data**.
2. Выбрать нужный канал/чат и включить **Files**.
3. Поднять лимит размера экспортируемого файла выше максимального отсутствующего вложения — минимум **13 MB**, безопаснее 20–50 MB.
4. Повторить экспорт только нужного канала или периода, сохранив каталог `files/`.
5. Проверить наличие 15 PDF по Message ID и имени из recovery-ledger.
6. Для каждого полученного файла записать SHA-256, байты, число страниц и визуально проверить первую/последнюю страницу.
7. Не заменять извлечённые из родительского «Христианина» приложения оригинальными Telegram-файлами: хранить оба как provenance-объекты и сравнить хеши/страницы.

## Альтернативы

- попросить владельца канала повторно переслать оригинальные PDF без сжатия;
- извлечь приложения из уже проверенных родительских PDF «Христианина»;
- заказать фондовые копии для выпусков без открытого родителя.

## Запрет

Нельзя создавать «восстановленный PDF» из скриншотов Telegram-аннотации или веб-превью: это не исходное факсимиле.

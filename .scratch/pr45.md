## Правило 25: почему индекс не decorations

Гейт (`scripts/validate_atonement_corpus_integrity.py`, 1925 строк, 26 правил) проверяет индекс:

* периметр: каждая запись лежит в объявленной папке, `driveId` уникальны, папки `10.x` из `scope.folderIds`
  описаны записями `kind=folder`, у файла есть размер, у папки — нет;
* права и статус чтения берутся из объявленных перечней, а не из того, что было под рукой;
* пометка «УСТАРЕЛО» в имени обязана совпадать с классом `HOLD_superseded` **в обе стороны**: устаревшее без
  пометки читается как живое, а пометка без класса — как пугало;
* лестница статусов: `registry_linked` невозможен без печатного локатора и без непустого `citedBy`,
  `unopened` не может иметь `citedBy`;
* каждая `FP-nn` существует в реестре массы, каждый `Q-nn` — в его очереди, каждая `Onn` — в очереди добычи
  `05_`, каждый `gitFile` — на диске;
* имя зеркала реестра, обещающее md5 и размер, сверяется с фактом в дереве; расхождение допускается только с
  явным `lagBehindGit`;
* объявленные в `driveMirrors.fileNN` зеркала обязаны иметь запись в индекса либо быть названными в
  `libraryIndex20261023.mirrorsOutsideScope` (два Docs-ярлыка в корне серии — исключение объявлено полем, а не
  вшито в правило);
* все числа блока `libraryIndex20261023` (records / files / folders / materials / materialsWithLocators /
  byRights / byReadState / driveBytesSum / largestBytes / scopeFolders) переснимаются тем же обходом, которым

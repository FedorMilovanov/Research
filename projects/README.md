- **`lord-god-strength/RULES.md`** — все правила канала «Господь Бог — Сила Моя»: идентификаторы, разметка, устройство описания, закрепы, Telegram, требования к тексту, источники, гейты. Один файл, второй свод правил не нужен.

- **`gb-is-my-strength/reader-platform/`** — материал другого проекта, к гимнам не относится.

Материал и исследование по гимнам живут в `SUNO_HYMNS/`, а не здесь. Идентификаторы каналов, состав плейлистов и платформенное поведение разметки — в репозитории `video-channel-manager`; при расхождении с этим каталогом побеждает `video-channel-manager` по ID и плейлистам, этот файл — по редакционным требованиям.

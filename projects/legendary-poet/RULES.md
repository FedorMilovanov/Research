# The Legendary Poet — Легендарный Поэт — мост к правилам канала

`project_key: legendary-poet` · литературный проект: поэзия, музыкальные интерпретации, визуальные реконструкции, AI-эксперименты.

Этот файл **не второй свод правил**. Их у канала три, и все три лежат не здесь. Здесь — указатель на них, разница с hymns-каналом и открытые вопросы, которые нельзя решать молча.

## 2. Чем этот канал отличается от hymns-канала

Общая механика — в [`../COMMON_RULES.md`](../COMMON_RULES.md). Различия, из-за которых нельзя переносить текст из одного канала в другой:

| | «Господь Бог — Сила Моя» | «The Legendary Poet» |
|---|---|---|
| начало описания | сразу по существу, первый абзац без разметки | первые две строки — плейлисты, строки 3–6 — соцсети, потом абзацы |
| объём описания | 3500–4600 | 3500–4600, лимит 5000 |
| выделения | 10–12 на текст | **3–4 жирных и 2–3 курсивных**, по 1–3 слова |
| названия | по смыслу | **ровно 5 вариантов**, до 70 знаков, без разметки |
| Shorts | не делается | отдельный блок 500–600 знаков |
| теги | нет | строка `ТЕГИ: …`, 15–25 штук, до 480 знаков |
| закреп | 1400–1600 знаков, вопрос не обязателен | 500–900 знаков, **вопрос с двумя вариантами ответа обязателен** |
| о чём нельзя | называть адаптацию переводом, выдавать гимн за богослужебный | упоминать Suno, AI, вокал, аранжировку, «звучание» |

## 4. Открытые расхождения — решает владелец

1. **VK-адрес.** Мастер-промт фиксирует `https://vk.com/thelegendarypoet`; реестр `video-channel-manager` называет каноническим `https://vk.ru/thelegendarypoet`, а `vk.com` — совместимым. Пока в блоке ссылок стоит адрес из промта дословно; менять его агент не вправе.
2. **Suno в названиях.** Промт запрещает «Suno» и «AI» в названиях и упоминание Suno в описании. У опубликованных роликов в названиях стоит «SUNO AI Cover», в тегах — «Suno AI», «Suno 5.0». Для новых работ действует промт; старые названия не переписываются без решения владельца.
3. **Сайт проекта** числится legacy-значением: перед массовой волной нужна живая проверка.
4. **Каталог работ канала** не восстановлен: известно, что работ больше одной, но списка с ID и датами нет.

## 5. Перенос мастер-промта

Промт — единственный документ, описывающий полный YouTube-пакет этого канала, и до 2026-10-26 он не лежал ни в одном репозитории. Его место — `TheLegendaryPoet`, рядом с `suno/AGENT.md`, потому что там живёт весь остальной контур канала.

Пока перенос не сделан, копия здесь помечена как копия, а не как источник. После переноса этот файл должен оставить в § 1 строку-указатель и удалить копию, чтобы не было двух версий одного промта.

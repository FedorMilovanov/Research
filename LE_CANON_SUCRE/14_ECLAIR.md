The current crawler timed out on direct page navigation, so the exact p. 50 column has **not** yet been inspected there.

Evidence decision:

- 1861 volume identity/archive object = `A2 INSTITUTIONAL OBJECT IDENTIFIED`;
- exact 2 Feb 1861 p. 50 col. 1 locator = `TIGHT SECONDARY LOCATOR`;
- exact page inspection = `LOCATOR_HOLD`;

## Breton / regional terminology

For Kouign-Amann:

- `kouign` = cake in Breton context;
- `amann` = butter;
- query both Breton orthography and French regional records;
- prioritize Douarnenez municipal/departemental archives and newspapers over modern etymology pages.

## OCR strategy

For nineteenth-century French corpora, search:

- hyphenated and non-hyphenated forms;
- omitted accents: `eclair`, `opera`;
- OCR confusions: `Saint-Honore`, `St Honore`, `religieuse` near `flan`, `duchesse` near `pâte à choux`;
- name variants: `Julien/Jullien`, `Anton/Antoine Rumpelmayer`, `letchi/litchi`.

For Gallica use full-text + date filters + proximity search, not ordinary web search alone:
https://gallica.bnf.fr/accueil/fr/html/aide-a-la-recherche

## Query evidence rule

A successful query is discovery, not evidence. Every promoted result must resolve to a stable object/page/issue locator and receive its own evidence/access/locator/rights/publication state.

## 1. Why this file exists

Several public sources describe Steven Lawson's post-September-2024 care using similar but non-identical language. Because the same Nashville church environment appears repeatedly, it is tempting to collapse all unnamed people into one group.

That would be methodologically unsound.

This file preserves the distinct role sets before attempting identification.

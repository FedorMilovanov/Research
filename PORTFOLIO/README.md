# PORTFOLIO — личный презентационный слой

Каталог с материалами о профессиональном профиле и продуктах. Это **не исследовательский корпус** и не часть evidence-модели: каталог не входит в `data/research-authority-registry-v1.json`, не переопределяет `CURRENT_AUTHORITY.md`, `AGENT_RULES.md` и `data/repository-evidence-policy-v2.json` и не может использоваться как источник для research-утверждений.

**Срез данных:** 1 ноября 2026. Метрики сняты через GitHub API и проверены на живых доменах; машинная таблица — в `METRICS.csv`.

## Три вывода

1. **Актив уже построен.** Пять живых продуктов, ≈758 000 строк продуктового кода, 239 CI-пайплайнов, ≈120 000 запусков, ≈690 000 слов редакционного контента. Это не учебные проекты.
2. **Дифференциатор — метод, а не код.** `AuditRepo`, `Research`, контракты и гейты дают то, что называют AI reliability и agent governance: «ИИ-агентам можно верить». Компетенция редкая и растущая.
3. **Разрыв в упаковке.** Ноль звёзд, ноль описаний, ноль англоязычных артефактов, ни одной цифры результата. Ближайшие три недели нужно упаковывать, а не писать код.

## Порядок действий

1. Прочитать `AUDIT_RU.md` §8 (реестр рисков) и §9 (красные линии) — чтобы не сломать портфолио первым же текстом.
2. Создать репозиторий `FedorMilovanov/FedorMilovanov` с README из `PROFILE_README.md` §1. Пятнадцать минут, максимальный эффект на единицу времени.
3. Проставить описания и topics из `PROFILE_README.md` §2, архивировать три мёртвых репозитория.
4. Заполнить квадратные скобки в `PORTFOLIO_RU.md` §9 реальными цифрами: трафик, заказы, подписчики, установки.
5. Затем — английская версия и один текст «как я делаю ИИ-сборку проверяемой».

## Оговорка о цифрах

Все технические метрики проверяемы по `METRICS.csv` и GitHub API. Два места, где легко соврать, и как это обойдено:

- **Строки кода.** ≈758 000 строк продуктового кода и ≈58 000 строк исследовательских валидаторов. Итог по всем репозиториям — 816 775 строк. Нигде не утверждается, что они написаны вручную.
- **Слова контента.** ≈690 000 слов редакционного контента на публичных сайтах (gospod-bog.ru, french.milovicake.ru, thelegendarypoet.ru) и отдельно ≈3,93 млн слов исследовательских документов в `Research`. Это разные величины, и они не складываются в «миллион слов статей».

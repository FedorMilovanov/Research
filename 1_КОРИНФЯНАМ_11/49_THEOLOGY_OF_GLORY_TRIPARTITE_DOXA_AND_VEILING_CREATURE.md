# Трёхчастная теология славы (Doxa) и сокрытие человеческого величия пред Богом

**Досье:** `1COR11-THEOLOGY-OF-GLORY-TRIPARTITE-DOXA`  
**Канонический охват:** 1 Кор. 11:7, 15; Ис. 6:1–4; 2 Кор. 3:18; 4:6; Откр. 4:10  
**Статус:** `PRIMARY THEOLOGICAL AND LITURGICAL AUDIT (LEVEL B1)`

---

## 1. Трёхчастная иерархия славы в 1 Кор. 11

В 11-й главе апостол Павел выстраивает глубочайшую **теологию славы (`δόξα`)**, охватывающую три взаимосвязанных уровня бытия:[^1]

```text
               ТРЁХЧАСТНАЯ ТЕОЛОГИЯ СЛАВЫ (1 КОР. 11)
┌────────────────────────────────────────────────────────┐
│ 1. БОЖЕСТВЕННАЯ СЛАВА (Doxa Theou / 11:7):             │
│    Несотворённая, абсолютная слава Творца.             │
│    Мужчина сотворён как прямой образ и слава Бога,     │
│    призванный отражать владычество Господа.            │
├────────────────────────────────────────────────────────┤
│ 2. ЧЕЛОВЕЧЕСКАЯ / БРАЧНАЯ СЛАВА (Doxa Andros / 11:7):  │
│    Женщина — слава мужчины (венец и красота сотворён-  │
│    ного человеческого рода, Быт. 2:23).                │
├────────────────────────────────────────────────────────┤
│ 3. ПРИРОДНАЯ ТЕЛЕСНАЯ СЛАВА (Doxa Autē / 11:15):       │
│    Длинные волосы — слава самой женщины, её природное  │
│    украшение и венец красоты.                          │
└────────────────────────────────────────────────────────┘
```

## 2. Литургический принцип сокрытия тварной славы (Ис. 6; 1 Кор. 11)

Главный богословский вопрос: **Почему женщина должна быть покрыта на богослужении, а мужчина — открыт?**

Ответ кроется в литургическом законе сокрытия тварного величия пред величием Творца:[^2]

```text
                  ЛИКУРГИЧЕСКИЙ ЗАКОН СЛАВЫ
┌────────────────────────────────────────────────────────┐
│ ПРИМЕР СЕРАФИМОВ (Исх. 6:2):                           │
│ Небесные серафимы, предстоя пред Престолом Божиим,     │
│ ДВУМЯ КРЫЛЬЯМИ ЗАКРЫВАЛИ ЛИЦА СВОИ И ДВУМЯ КРЫЛЬЯМИ   │
│ ЗАКРЫВАЛИ НОГИ СВОИ, сокрывая тварную красоту пред     │
│ Несотворённым Сиянием Святого Бога!                    │
├────────────────────────────────────────────────────────┤
│ СОБРАНИЕ ЦЕРКВИ (1 Кор. 11:7–10):                      │
│ • Мужчина предстоит открытым, являя славу Бога;        │
│ • Женщина покрывает голову, сокрывая славу человека    │
│   (свою красоту, волосы и брачную славу мужа),         │
│   ДАБЫ В СОБРАНИИ СВЯТЫХ ВОССИЯЛА ТОЛЬКО СЛАВА ГОСПОДА!│
└────────────────────────────────────────────────────────┘
```

Как объясняют Рой Чампа и Брайан Рознер:
> «Покрывало женщины в собрании выполняет священную функцию: оно выводит из фокуса человеческую красоту и славу мужа, чтобы всё собрание было направлено исключительно на поклонение Богу и Христу».[^3]
